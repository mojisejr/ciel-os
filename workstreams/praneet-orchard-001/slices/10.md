# 10. งานที่ยังไม่คิดเงิน

**ทำไม:** เจ้าของบันทึกงานของทีมที่ยังไม่รู้ชั่วโมงและยังไม่ได้คิดเงินไม่ได้ ฟอร์มบังคับชั่วโมง
จึงต้องใส่ชั่วโมงกับราคาสมมุติ แล้วยอดค้างจ่ายผิด และงานที่มีคนทำแต่ไม่คิดเป็นเงินเลือก "ไม่คิดเงิน" ไม่ได้
(revision 1.1 ทำก่อน slice 8 เพราะเจอทุกวัน และ slice 8 ต้องใช้ค่าแรงที่ถูก)

1. **praneet-web:**
   - **ยังไม่ได้นับ:** งานเหมาและรายชั่วโมงเว้นจำนวนหรือชั่วโมงว่างได้ ทั้งจ่ายรายคนและจ่ายทั้งทีม
     งานนั้นยังไม่เป็นเงิน นับรวมกับงานที่ยังไม่ตั้งราคา หน้าของวันและหน้าคนงานบอกว่ายังไม่คิดเงิน
     จนเจ้าของกลับมาใส่ ชั่วโมงที่ใส่ยังต้องเป็นทีละครึ่งชั่วโมง migration 021 ขยาย check ของงานทีมอย่างเดียว
   - **ไม่คิดเงิน:** ปุ่มที่สี่ข้างรายวัน เหมา รายชั่วโมง ใช้ได้เมื่อเลือกคนแล้ว งานนั้นไม่เกิดค่าแรง
     และไม่นับเข้าค่าแรงรายวัน
   - งานที่รู้ราคาแล้วแต่ยังไม่จ่ายบันทึกตามเดิม ยอดค้างจ่ายจนกว่าจะบันทึกการจ่าย
2. **praneet-office:** `orchard add` ส่งต่อให้ API อยู่แล้ว ไม่ต้องแก้ ถ้าทดสอบแล้วไม่ผ่านจึงแก้

ไม่ทำใน slice นี้: แก้งานวันที่ 29 และ 30 ต.ค. ที่บันทึกไปแล้ว เจ้าของแก้เอง หรือ agent แก้เมื่อเจ้าของสั่ง

## Acceptance

- งานรายชั่วโมงและงานเหมาของทีมและของรายคนบันทึกได้โดยไม่ใส่ชั่วโมงหรือจำนวน ทั้งจากฟอร์มและ API
  ยอดค้างจ่ายไม่เพิ่ม หน้าของวันและหน้าคนงานบอกว่ายังไม่คิดเงิน ใส่ทีหลังแล้วยอดถูก
- เลือกคนแล้วบันทึกแบบไม่คิดเงินได้ ไม่เกิดค่าแรงรายวันและไม่เกิดยอด
- test ของ praneet-web ครอบคลุมทั้งสองแบบ เจ้าของ merge PR
