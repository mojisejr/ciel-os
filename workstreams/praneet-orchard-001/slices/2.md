# 2. คนงาน งานรายวัน ค่าแรง และเงินเบิก

**ทำไมก่อน:** เป็นส่วนที่เจ้าของใช้จริงทุกวัน เรื่องเงินต้องแม่นยำ และทุกงานผูกกับค่าแรง

1. **praneet-web ข้อมูล:** migration แบบเพิ่มอย่างเดียว
   - แปลง P-1 ถึง P-4 (P-4 ผูกกับ lot ของร้าน), คนงาน (ชื่อ เบอร์โทร รายละเอียดอิสระ และค่าแรงต่อวันถ้าไม่ใช่อัตราปกติ),
     ทีม (กลุ่มคนงานที่มีรายชื่อสมาชิก), ชนิดงานที่เจ้าของเพิ่มเองได้
     พร้อมหมวดต้นทุนของตาไก๊ที่ agent ผูกให้ และวิธีคิดเงินตั้งต้นของงานนั้น
   - งาน: วันที่ ชนิดงาน แปลงได้หลายแปลง คนได้หลายคน ทีม หรือเจ้าของทำเอง หมายเหตุ
   - **วิธีคิดเงินของงาน (revision 0.3):** รายวัน · เหมา (จำนวน × ราคาต่อหน่วย) · รายชั่วโมง (ชั่วโมง × ราคาต่อชั่วโมง)
     ตั้งตามชนิดงาน เปลี่ยนได้ทีละงาน เหมาและรายชั่วโมงเลือกได้ว่า**จ่ายทั้งทีม**หรือ**จ่ายรายคน**
     ("บางทีก็จ่ายทั้งทีม บางทีก็จ่ายรายคน") จ่ายรายคนเก็บจำนวนหรือชั่วโมงของแต่ละคน ราคาเปลี่ยนรายคนได้
   - **ชั่วโมงทีละครึ่งชั่วโมงเท่านั้น:** ฐานข้อมูลเก็บเป็นจำนวนครึ่งชั่วโมง ไม่มีนาที ("จะไม่มาคิดค่าแรง x นาทีเป็นอันขาด")
   - **ค่าแรงรายวัน:** คนที่มีชื่อในงานแบบรายวันของวันนั้นได้ 1 วัน เจ้าของแตะเป็นครึ่งวันที่ตัวคนได้
     งานเหมาและรายชั่วโมงไม่นับเข้าค่าแรงรายวัน ไม่มีงานคือไม่ได้ ไม่มีช่องลา เจ้าของทำเองไม่คิดค่าแรง
   - **เงินพิเศษ:** บวกเพิ่มต่อคนต่อวันพร้อมเหตุผล ไม่แก้ค่าแรงตั้งต้น
   - เงิน: แต่ละคนหรือทีมที่รับเงินรวม มียอดค่าแรงค้างจ่ายกับเงินเบิกค้าง คำนวณจากรายการเท่านั้น
     ทุกยอดเกิดตอนบันทึกงาน จ่ายเมื่อจ่ายจริง: เบิก, เคลียร์ค่าแรง (โอน เงินสด เติมมือถือ หักเบิก)
     แสดงยอดก่อนและหลังทุกครั้ง ยอดยกมาตอนเริ่มเป็นยอดที่เจ้าของยืนยัน
   - แก้หรือซ่อนได้ ไม่ลบจริง ทุกการเปลี่ยนเข้า `audit_events`
2. **praneet-web หน้าจอ (ตัวอย่างรอบ 2 แบบ 1 ที่เจ้าของเลือก):**
   - **หน้าของวัน (revision 0.4):** สองแท็บ `งาน | เงิน` แต่ละแท็บยาวตามเรื่องของตัวเอง (วันที่งานมากสุดใน Sheet มี 8 งาน)
     แท็บงานจัดตามแปลง แท็บเงินบอกเงินของวันนี้ต่อคนหรือต่อทีมบรรทัดเดียว
     (รายวัน + เหมา + ชั่วโมง + พิเศษ) แต่ละบรรทัดมีปุ่ม "จ่ายแล้ว" ที่ขยายในบรรทัดให้เลือกวิธีจ่าย
     เพราะส่วนใหญ่จ่ายจบในวันนั้น ปุ่ม "+ เพิ่มงาน" ติดล่างจอ หน้าไม่ยาวขึ้นตามจำนวนคน
   - **หน้าเพิ่มงาน:** แปลง · ใครทำ · ทำอะไร · คิดเงินแบบ · หมายเหตุ ฟอร์มเดียวทุกวิธีคิดเงิน
     ปุ่ม "บันทึก แล้วเพิ่มต่อ" ติดล่างจอ อยู่หน้าเดิมและตั้งแปลงกับคนตามงานก่อน
     เพราะเจ้าของบันทึกเป็นชุดตอนเย็น หรือทันทีก็ได้
   - **ใครทำ:** ปุ่มเฉพาะคนที่มาใน 14 วันล่าสุด เลือกได้หลายคน ปุ่มทีมเลือกสมาชิกทั้งหมดแล้วแตะคนที่ไม่มาออก
     คนอื่นค้นชื่อ ไม่เจอก็เพิ่มเป็นคนใหม่จากช่องค้นได้ทันทีด้วยชื่ออย่างเดียว รับวันละราว 15 คน
   - **ทำอะไร:** ปุ่มงานที่ใช้บ่อยของแปลงนั้น 6–8 ปุ่ม เรียงคงที่ ปรับสัปดาห์ละครั้ง ปักหมุดได้ ไม่เจอก็พิมพ์ คำใหม่ใช้ได้ทันที
   - **คิดเงินแบบ:** ขึ้นตามชนิดงาน รายวันไม่มีช่องเพิ่ม จ่ายรายคนตั้งค่าทุกคนครั้งเดียวแล้วแก้เฉพาะคนที่ต่าง
     ชั่วโมงใช้ปุ่ม − / + ทีละครึ่งชั่วโมง พ่นยาไปฟอร์มของตัวเองใน slice 5
   - **งานสวนทั้งหมด (revision 0.4):** วันละแถว วันล่าสุดก่อน กรองด้วยเดือน แปลง คน ชนิดงาน วิธีคิดเงิน
     และค้นคำในหมายเหตุ ผลที่กรองแสดงทุกงานที่ตรง แตะแล้วไปหน้าของวันนั้น
   - **คนงาน (revision 0.4):** รายชื่อ เพิ่ม แก้ และซ่อน (ไม่ลบจริง เพราะประวัติเงินผูกอยู่) หน้าของแต่ละคนมี
     ชื่อ เบอร์โทร รายละเอียด (ถนัดอะไร รู้อะไร ซื้ออะไรจากเขาได้) งานย้อนหลัง ยอดค้าง หนี้เบิก และประวัติการจ่าย
     เงินทุกรายการผูกกับคนในรายชื่อเท่านั้น
   - ไม่มีป๊อปอัป ใช้ชิ้นส่วนกลางของหลังบ้านตาม `DESIGN.md` ตัวอย่างของหน้าเพิ่มงานและหน้าของวันตามกติกา 0.3
     ให้เจ้าของดูก่อนเขียนโค้ด
3. **API สำหรับ office:** เขียนงานและการเงินผ่านกติกาเดียวกับฟอร์ม
4. **praneet-office:** คำสั่งอ่านงานและยอดค่าแรง คำสั่งที่ agent ใช้ผูกชนิดงานกับหมวดให้เจ้าของตรวจ และ runbook ถ้าเจ้าของเห็นว่าจำเป็น

## Acceptance

- เจ้าของบันทึกวันที่ทำหลายงานได้ ค่าแรงรายวันคิดหนึ่งวันหรือครึ่งวันต่อคน ไม่ใช่ต่องาน
- คนเดียวกันในวันเดียวทำงานรายวันครึ่งวันและงานเหมาหรือรายชั่วโมงได้ ยอดแยกถูกและรวมในบรรทัดเดียว
- ทีมจ่ายทั้งทีมและจ่ายรายคนคิดถูก ชั่วโมงที่ไม่ใช่ครึ่งชั่วโมงถูกปฏิเสธทั้งจากฟอร์มและจาก API
- วันที่ 19 ส.ค. 2569 (6 คน 5 งาน) บันทึกได้ครบบนมือถือโดยหน้าไม่บวม และวันที่ 24 ต.ค. (8 งาน) อ่านได้ในแท็บงาน
- คนใหม่เพิ่มจากหน้าเพิ่มงานด้วยชื่ออย่างเดียว แล้วเติมเบอร์และรายละเอียดทีหลังได้ คนที่ซ่อนไม่ขึ้นให้เลือกแต่ประวัติยังอยู่
- กรองงานทั้งหมดด้วยแปลงกับชนิดงานแล้วได้ทุกงานที่ตรง
- ยอดค้างและหนี้เบิกเริ่มจากยอดที่เจ้าของยืนยัน และคิดต่อจากรายการถูก (การเทียบกับ Sheet อยู่ใน slice 3)
- test ของ praneet-web ครอบคลุมกติกาค่าแรง ชั่วโมง เงินพิเศษ และเงินเบิก PR ทั้งสอง repo เจ้าของ merge แล้ว
