# 2. คนงาน งานรายวัน ค่าแรง และเงินเบิก

**ทำไมก่อน:** เป็นส่วนที่เจ้าของใช้จริงทุกวัน เรื่องเงินต้องแม่นยำ และทุกงานผูกกับค่าแรง

1. **praneet-web:** migration แบบเพิ่มอย่างเดียวตามโครงที่ตกลงใน slice 1
   หน้า `/ops` ให้เจ้าของกรอกวันทำงาน งาน และการเบิกจ่ายบนมือถือ แก้หรือซ่อนได้ ไม่ลบจริง
   ยอดค้างและหนี้เบิกของแต่ละคนคำนวณจากรายการ ไม่พิมพ์ตัวเลขยอดเอง
2. **API สำหรับ office:** เขียนงานและการเงินผ่านกติกาเดียวกับฟอร์ม
3. **praneet-office:** คำสั่งอ่านงานและยอดค่าแรง และ runbook ถ้าเจ้าของเห็นว่าจำเป็น

## Acceptance

- เจ้าของบันทึกวันที่ทำหลายงานได้ ค่าแรงคิดหนึ่งวันหรือครึ่งวันต่อคน ไม่ใช่ต่องาน
- ยอดค้างและหนี้เบิกตรงกับ Sheet สำหรับช่วงที่นำเข้า (รายงานจาก slice 3)
- test ของ praneet-web ครอบคลุมกติกาค่าแรงและเงินเบิก PR ทั้งสอง repo เจ้าของ merge แล้ว
