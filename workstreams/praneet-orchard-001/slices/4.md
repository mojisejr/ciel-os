# 4. ระบบเขียน Calendar ทางเดียว

**ทำไม:** ปัญหาเดิมคือข้อมูลไม่ขึ้นอย่างแน่นอน ถ้าระบบเขียน event เองจากรายการในฐานข้อมูล ปัญหานั้นจบ

1. **praneet-web:** งานที่บันทึกแล้วสร้าง event ในปฏิทินหลักของเจ้าของ
   - **วันละ 1 event แบบทั้งวัน (revision 0.5):** ปฏิทินนี้เป็นปฏิทินหลักของเจ้าของ งานละ event จะทับนัดส่วนตัว
     หัวเรื่อง `สวน · <จำนวน> งาน · <ชื่อคนและทีม>` รายละเอียดเรียงตามแปลง งานละบรรทัด
     `• งานตามคำของเจ้าของ — ใคร` หมายเหตุใต้บรรทัด ไม่มี META, tag, เลขรายการ หรือข้อความที่ AI เรียบเรียง
   - `extendedProperties` บอกที่มา วันที่ และเลขรายการ งานในวันนั้นเปลี่ยนแล้ว event ของวันนั้นสร้างใหม่ตาม
   - ไม่มีอะไรเกี่ยวกับการจ่ายเงิน ทั้งจำนวนเงิน ครึ่งวัน และชั่วโมง รายการที่เป็นเงินอย่างเดียวไม่ขึ้นปฏิทิน
     เพราะคนในบ้านดูปฏิทินนี้ ไม่มีลิงก์ Sheet
   - **ลิงก์กลับเข้า app (revision 0.4):** บรรทัดเดียวท้ายรายละเอียด ไปหน้าของวันนั้นใน `/ops`
     คนในบ้านที่แตะเจอหน้าเข้าสู่ระบบ เจ้าของรับได้ ("ไม่เป็นไร")
   - ไม่มี Morning Brief ในปฏิทิน
   - เขียนไม่สำเร็จไม่ทำให้การบันทึกหาย และเห็นได้ว่ายังค้างกี่รายการ
2. **สิทธิ์:** บัญชีระบบของ Google ใน Cloud project เดิมของเจ้าของ แชร์ให้เฉพาะปฏิทินนี้ เจ้าของเป็นคนสร้างกุญแจ
   วิธีให้สิทธิ์ (ไฟล์กุญแจ หรือให้ Vercel ขอสิทธิ์โดยไม่มีไฟล์กุญแจ) agent ค้นและเสนอก่อนเริ่ม

## Acceptance

- event ใหม่และ event เก่าอยู่ในปฏิทินเดียวกัน แยกกันได้ด้วยข้อมูลซ่อนและหัวเรื่อง
- วันที่มีหลายงานมี event เดียว แก้งานแล้ว event ของวันนั้นเปลี่ยนตาม
- คนในบ้านที่ดูปฏิทินไม่เห็นเงิน ครึ่งวัน หรือชั่วโมง
- แตะลิงก์ใน event แล้วเปิดหน้าของวันนั้นใน `/ops` ได้
- test ไม่เรียก Google จริง ใช้ตัวแทนในเครื่อง
