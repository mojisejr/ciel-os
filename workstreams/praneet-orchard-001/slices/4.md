# 4. ระบบเขียน Calendar ทางเดียว

**ทำไม:** ปัญหาเดิมคือข้อมูลไม่ขึ้นอย่างแน่นอน ถ้าระบบเขียน event เองจากรายการในฐานข้อมูล ปัญหานั้นจบ

1. **praneet-web:** รายการงานที่บันทึกแล้วสร้าง event ในปฏิทินเดิมของเจ้าของ พร้อม `extendedProperties`
   บอกที่มาและเลขรายการ แก้หรือซ่อนรายการแล้ว event เดิมเปลี่ยนตาม ไม่มีจำนวนเงินใน event
   เขียนไม่สำเร็จไม่ทำให้การบันทึกหาย และเห็นได้ว่ายังค้างกี่รายการ
2. **สิทธิ์:** บัญชีระบบของ Google ที่เจ้าของแชร์ให้เฉพาะปฏิทินนี้ เจ้าของเป็นคนสร้างกุญแจ

## Acceptance

- event ใหม่และ event เก่าอยู่ในปฏิทินเดียวกัน แยกกันได้ด้วยข้อมูลซ่อนและหัวเรื่อง
- คนในบ้านที่ดูปฏิทินไม่เห็นเงิน
- test ไม่เรียก Google จริง ใช้ตัวแทนในเครื่อง
