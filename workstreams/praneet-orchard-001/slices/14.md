# 14. กล่องติดตามงานบนหน้าวันนี้

**ทำไม:** เจ้าของอยากรู้ว่าเรื่องที่เขาสนใจในแต่ละแปลงทำล่าสุดเมื่อไหร่ ผ่านมากี่วัน ชื่องานที่บันทึกปนหลายแบบ
และงานที่หน้าตาเหมือนกันอาจไม่ใช่เรื่องเดียวกัน ("ขูดต้นแล้วพ่นยา" ไม่ใช่รอบพ่นยา) จึงนับเฉพาะงานที่เขาใส่ในกล่องเอง
แบบแรกของ slice นี้ (ป้ายของคำ revision 1.7 และ 1.8) ถูก rollback แล้ว

1. **ตัวอย่างก่อนสร้าง:** กล่องบนหน้าวันนี้ หน้ากล่อง และส่วน "ติดตามในกล่อง" ในฟอร์ม บนหน้าจริงที่ 390 และ 1280
   สว่างและมืด เจ้าของเลือกก่อนเขียนหน้าจริง ตัวอย่างไม่ commit
2. **praneet-web, ข้อมูล:** กล่องคือแปลงหนึ่งกับชื่อสั้นหนึ่ง เปิดหรือปิด งานหนึ่งอยู่ได้หลายกล่องของแปลงตัวเอง
   ทุกการเพิ่ม เอาออก เปลี่ยนชื่อ ปิด และเปิด เก็บใน audit migration เดียวกันลบคอลัมน์ว่างของ 027
   (ตรวจก่อนว่าว่างจริง ถ้าไม่ว่างให้หยุด)
3. **praneet-web, การนับ:** กล่องนับวันจากงานที่ยังไม่ซ่อนและวันที่ใหม่สุดในกล่อง ใส่งานเก่าที่ลืมแล้วตัวเลขไม่ย้อน
4. **praneet-web, หน้าวันนี้:** กล่องที่เปิดอยู่ทั้งหมดบนสุด วันมากสุดอยู่บน แต่ละกล่องบอกจำนวนวัน วันที่
   และชื่องานล่าสุด แตะแล้วไปหน้ากล่อง
5. **praneet-web, หน้ากล่อง:** งานล่าสุดและลิงก์ รอบก่อน ๆ พร้อมระยะห่าง "เพิ่มงานที่ลืม" (งานของแปลงนั้นหลังรอบล่าสุด
   แตะเลือก) เอางานออก เปลี่ยนชื่อ ปิดและเปิดกล่อง
6. **praneet-web, ฟอร์มและหน้างาน:** ส่วน "ติดตามในกล่อง" ปิดไว้ก่อน เปิดแล้วเห็นกล่องของแปลงที่เลือก
   และ "+ กล่องใหม่" (กล่องใหม่ของงานหลายแปลงได้แปลงละกล่อง) หน้างานมี "ติดตามงานนี้" และบอกว่าอยู่กล่องไหน
7. **praneet-office:** คำสั่งอ่านกล่อง และใส่งานเข้ากล่อง (ทดลองก่อน เขียนเมื่อเจ้าของบอก) agent ถามก่อนถ้าเจ้าของไม่ได้บอกกล่อง

ไม่ทำใน slice นี้: หมวดงาน ป้ายของคำ การเดาจากชื่องาน สีหรือการเตือน จัดปุ่มกลมทั้งฟอร์มใหม่ โซนให้น้ำ (slice 15)
และ web app แยกสำหรับผู้ใช้อื่น

## Acceptance

- เจ้าของเลือกตัวอย่างแล้ว
- test ของ praneet-web: งานที่ไม่ได้อยู่ในกล่องไม่นับ งานเก่าที่ลืมใส่ทีหลังไม่ทำให้ตัวเลขย้อน ซ่อนงานล่าสุดแล้วกลับไปรอบก่อน
  กล่องปิดไม่ขึ้นหน้าแรก กล่องรับเฉพาะงานของแปลงตัวเอง และหน้าแรกอ่านได้ไม่ตัดคำที่ 360 รันใต้ตัวคุมหน่วยความจำ
- หลัง merge กล่องที่เจ้าของเริ่มจากงานเก่าบน production ตรงกับงานจริง และลิงก์ไปงานนั้น
