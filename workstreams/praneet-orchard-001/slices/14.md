# 14. การ์ดงานประจำบนหน้าวันนี้: พ่นยา ใส่ปุ๋ย ให้น้ำ ทำสาร

**ทำไม:** เจ้าของอยากรู้ทันทีว่าแต่ละแปลงไม่ได้พ่นยา ใส่ปุ๋ย ให้น้ำ ทำสาร มานานแค่ไหน เพื่อจัดเวลางาน
งานพ่นและใส่ปุ๋ยมีวิธีใส่และชนิดยาเฉพาะงานที่ใส่ยา ส่วนให้น้ำมีแค่ชื่องาน
ชื่องานในระบบ 183 คำปนไทยอังกฤษ ("Night Irrigation", "Irrigation & Spray") และมีคำที่หน้าตาเหมือนแต่ไม่ใช่
("ซ่อมท่อระบบน้ำ", "พ่นยาฆ่าหญ้า", "โรยปูนปรับสภาพดิน")

1. **ตัวอย่างก่อนสร้าง:** การ์ดสองแบบบนหน้าวันนี้จริง แบบ A ตามเรื่อง (สามใบ แปลงที่นานสุดอยู่บน)
   แบบ B ตามแปลง (แปลงละใบ สามแถว) ที่ 390 และ 1280 สว่างและมืด เจ้าของเลือกก่อนเขียนโค้ดจริง ตัวอย่างไม่ commit
   เจ้าของเลือก A แล้ว (revision 1.8)
2. **praneet-web, ป้ายของคำ:** คำเรียกงานมีป้ายได้หลายป้าย (พ่นยา ใส่ปุ๋ย ให้น้ำ) และสถานะยืนยัน แก้แล้วเก็บก่อนหลังใน audit
   ป้ายติดกับคำ แก้แล้วงานทุกวันที่ใช้คำนั้นเปลี่ยนตาม
3. **praneet-web, การนับ:** งานหนึ่งนับเรื่องที่ป้ายของคำบอก รวมกับที่ข้อมูลของงานบอกเอง:
   พ่นทางใบนับพ่นยา ยกเว้นถังที่มีแต่ยาฆ่าหญ้า หรือมีแต่สารบังคับออกดอกกับยาจับใบหรือปุ๋ย
   หว่าน โรย ราดโคนที่ยาทุกตัวเป็นปุ๋ยนับใส่ปุ๋ย พ่นลำต้น พ่นโคน และพ่นเฉพาะจุดไม่นับพ่นยา
   งานที่มียาชนิด "สารบังคับออกดอก" นับทำสาร ไม่ว่าวิธีใส่ไหน ถังที่ผสมยาฆ่าแมลงหรือยาเชื้อรานับพ่นยาด้วย
   ป้ายของคำไม่มี "ทำสาร" ทำสารมาจากชนิดยาเท่านั้น
   งานที่ซ่อนแล้วไม่นับ ป้ายที่ยังไม่ยืนยันนับแต่การ์ดบอกว่า "ยังไม่ยืนยัน"
4. **praneet-web, หน้าวันนี้:** การ์ดแบบ A บนสุด เรื่องละใบ ทุกแปลง แปลงที่นานสุดอยู่บน
   แต่ละแถวบอกจำนวนวัน วันที่ และชื่องานที่ใช้นับ แตะแล้วไปงานนั้น แปลงที่ไม่มีบันทึกบอกว่า "ยังไม่มีบันทึก"
   การ์ดทำสารมีแถวละแปลงและผลไม้ ("สวนล่าง · มังคุด") เฉพาะคู่ที่เคยทำสาร
5. **praneet-web, ฟอร์มงาน:** คำใหม่มีป้ายที่ระบบเดาใต้ชื่องาน แตะเปลี่ยนได้ และกลับมาแก้หรือยืนยันในหน้างานได้
   งานที่ใส่สารบังคับออกดอกให้แตะเลือกผลไม้จากรายการผลไม้ของระบบ บันทึกไม่ได้ถ้ายังไม่เลือก
   ชั้นยามีชนิดใหม่ "สารบังคับออกดอก" แยกจาก "ฮอร์โมน"
6. **praneet-office:** คำสั่งอ่านป้ายของทุกคำ และตั้งป้ายจากไฟล์ (ทดลองก่อน เขียนเมื่อเจ้าของบอก)
   agent เสนอป้ายให้ 183 คำ ส่งเจ้าของดูเฉพาะคำที่ได้ป้ายกับคำที่ไม่แน่ใจ แล้วตั้งเป็นยืนยันหลังเจ้าของตรวจ
   หลัง merge และเมื่อเจ้าของบอก: ย้ายทะวายกับสารมังคุดป้าไปชนิดสารบังคับออกดอก และตั้งผลไม้ของงานทำสารเก่า 3 งานตามชื่องาน

ไม่ทำใน slice นี้: เตือนเกินกำหนดหรือสี การ์ดเรื่องอื่นนอกจากสี่เรื่องนี้ แยกพ่นยาหรือใส่ปุ๋ยตามผลไม้ โซนให้น้ำ (slice 15)
และ web app แยกสำหรับผู้ใช้อื่น

## Acceptance

- เจ้าของเลือกแบบการ์ดจากตัวอย่างแล้ว
- เจ้าของตรวจรายการป้ายของคำเก่าแล้ว และป้ายที่ตั้งตรงตามที่เขาแก้
- test ของ praneet-web: ซ่อมท่อ พ่นยาฆ่าหญ้า ซื้อปุ๋ย โรยปูน ราดยาเชื้อราไม่นับ ปุ๋ยในถังพ่นนับพ่นยาอย่างเดียว
  ให้น้ำพร้อมใส่ปุ๋ยนับทั้งสอง พ่นลำต้นหรือพ่นเฉพาะจุดไม่นับ ถังที่มีแต่สารนับทำสารอย่างเดียว
  ถังสารผสมยาฆ่าแมลงนับทั้งสอง ทำสารแยกแถวตามแปลงและผลไม้ งานสารที่ไม่มีผลไม้บันทึกไม่ได้
  และการ์ดอ่านได้ไม่ตัดคำที่ 360 รันใต้ตัวคุมหน่วยความจำ
- หลัง merge การ์ดบน production ตรงกับงานล่าสุดจริงของแต่ละแปลง และลิงก์ไปงานนั้น
