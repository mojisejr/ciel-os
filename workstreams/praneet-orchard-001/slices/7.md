# 7. ตัวตรวจชุดยา

**ทำไม:** ผสมผิดแล้วตกตะกอนหรือดื้อยา เปลืองต้นทุน ชุดที่ agent เสนอต้องผ่านกฎที่มีแหล่งอ้างอิง
และใช้ยาที่มีบนชั้นจริง (revision 0.8)

1. **praneet-office:** ตรวจชุดที่ agent จัด ด้วยกฎจากผลตรวจ 16 ข้อ
   (`.assets/orchard-decision/chemical-rules-report-20261027.md`, git ไม่ track)
   - **ห้ามเด็ดขาด** เฉพาะกฎที่แหล่งหลักยืนยัน (FRAC, IRAC, ฉลาก) **เตือนพร้อมเหตุผล** เมื่อแหล่งรองรับบางส่วน
     กฎที่ไม่มีแหล่งไม่ใช้ จนกว่าเจ้าของเลือกเป็นค่าของตัวเอง ("ถ้าใช้แล้วเข้มไปตรงไหน เราปรับอีกที")
   - ข้อที่มาจากสรุปผลค้นหาต้องอ่านแหล่งตรงก่อนบังคับ ฉลากยาชนะกฎทั่วไปเสมอ
   - ประวัติที่ใช้ตรวจการสลับกลุ่ม: อย่างน้อย 60 วันจาก slice 6
   - ชุดที่เสนอใช้เฉพาะยาที่สถานะมีหรือเหลือน้อย บอกเหตุผล กฎที่ผ่าน และแหล่งอ้างอิงทุกครั้ง
     คิดความคุ้มจากราคาในคลังเมื่อมี
2. **runbook การจัดยา (revision 1.0 เป็นงานหลัก):** ใน praneet-office ลำดับที่ agent ทำเมื่อเจ้าของถามเรื่องจัดยา
   - อ่านชั้นยา ประวัติพ่นของแปลง diary และระยะใบผ่าน office ก่อน
   - ค้นตามลำดับ: ฉลากยา แล้ว FRAC / IRAC แล้วแหล่งรอง บอกทุกครั้งว่าแหล่งไหนเป็นหลัก แหล่งไหนเป็นรอง
   - ส่งชุดให้ตัวตรวจก่อนเสนอเจ้าของ เรื่องที่กฎยังไม่ครอบคลุมบอกว่า "ยังไม่ได้ตรวจด้วยกฎ"
   - เรื่องใหม่ที่เจอบ่อยกลายเป็นกฎได้เมื่อมีแหล่งและเจ้าของตกลง

## Acceptance

- ชุดที่ผ่านกฎแสดงเหตุผลและแหล่งอ้างอิงของทุกกฎ
- ชุดที่ฝ่ากฎถูกโค้ดปฏิเสธพร้อมชื่อกฎและแหล่งอ้างอิง
- ชุดที่มียาสถานะหมดหรือรอยืนยันถูกบอกชัด ไม่ผ่านเงียบ ๆ
- agent ใหม่ที่อ่าน runbook ตอบคำถามจัดยาได้ครบทุกขั้น และบอกได้ว่าข้อไหนผ่านกฎ ข้อไหนยังไม่ได้ตรวจ
