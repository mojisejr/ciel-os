# 5. ชั้นยาและ diary

**ทำไมก่อน:** การจัดยาต้องรู้ว่าบนชั้นมีอะไรเหลือ และสวนเจออะไรจริง ทั้งสองอย่างใช้ได้ทันที
ไม่ต้องรอกฎหรือประวัติพ่น (revision 0.8)

1. **praneet-web คลังยา:** คลังเดียวที่สวนกับแปลงพันธุ์ไม้ใช้ร่วมกัน ("เป็นคลังยาเดียวกันครับ")
   - ยาแต่ละตัว: ชื่อการค้า สารออกฤทธิ์ สูตรฟอร์มูเลชัน (WP / SC / SL / EC …) ขนาด ราคา และสถานะ
     มี / เหลือน้อย / หมด ไม่มีการหักจำนวนตอนพ่น
   - สารออกฤทธิ์และกลุ่ม FRAC/IRAC ที่ agent เติมติดป้าย "รอยืนยัน" จนเจ้าของยืนยันกับฉลาก
     กลุ่มคำนวณจากสารออกฤทธิ์ ไม่ใช้กลุ่มที่พิมพ์ไว้ใน Sheet
   - นำเข้า `Chemical_Catalog` 27 ตัวและ `Chemical_Receipes` 28 สูตรจาก Sheet ซ้ำได้ ทุกตัวรอยืนยัน
     สถานะตั้งต้นไม่รู้ จนกว่าเจ้าของบอกว่าอะไรมีอะไรหมด
   - เจ้าของเพิ่มยาที่ซื้อใหม่ และแตะเปลี่ยนสถานะได้ใน `/ops`
2. **praneet-web diary:** แต่ละแปลงแต่ละวันมีโน้ตเดียว พิมพ์อิสระ กลับมาแก้ได้ตลอด
   และมีโน้ตของวันที่ไม่ผูกแปลงได้อีกหนึ่ง แปลงที่วันนั้นไม่ได้เข้าไม่ต้องจด
   ไม่มีปุ่มสิ่งที่เจอหรือระดับ ไม่มีวันนัดตรวจหรือรายการค้าง ผลที่เห็นจดเป็นคำพูดในวันนั้น
   ไม่ขึ้นปฏิทิน บอกว่าใครบันทึก แก้แล้ว `audit_events` เก็บก่อนหลัง
3. **praneet-office:** คำสั่งอ่านชั้นยา (ตามสถานะ กลุ่ม และป้ายรอยืนยัน) กับ diary ล่าสุดของแปลง
   และคำสั่งแก้สถานะยา เพิ่มยา และจดหรือแก้ diary ตามที่เจ้าของเล่า ผ่าน API ของ `/ops`
   แสดงสิ่งที่จะเขียนก่อนเขียนเสมอ

## Acceptance

- นำเข้าไฟล์เดิมซ้ำแล้วไม่เปลี่ยนอะไร ยาและสูตรทุกตัวรอยืนยัน
- เจ้าของหรือ agent เปลี่ยนสถานะยาแล้ว office อ่านชั้นยาได้ตรงกับหน้า `/ops`
- diary ของแปลงในวันเดียวกันมีโน้ตเดียว แก้ได้ และไม่มีอะไรขึ้นปฏิทิน
- agent อ่านชั้นยาและ diary ล่าสุดของแปลงได้ด้วยคำสั่งเดียวตอนจัดยา
