# 5. คลังยา การพ่น รอบการผลิต การจัดยาตามกลุ่ม และ diary

**ทำไม:** เจ้าของจัดยาให้ถูกโดยไม่เปิดตำราไม่ได้ งานนี้ต้องการประวัติการพ่นตามกลุ่มยาและคลังที่เป็นปัจจุบัน

1. **praneet-web:** คลังยา (มี / เหลือน้อย / หมด, เพิ่มของใหม่), สูตรประจำ, การพ่นที่เก็บกลุ่มยาของทุกตัว
   ระยะใบ ระยะแมลง และสิ่งที่เจอ, รอบการผลิตของแต่ละแปลง, diary ส่วนตัวที่ไม่ขึ้นปฏิทิน
2. **praneet-office:** คำสั่งที่รวมประวัติกลุ่มยาของแปลงเป้าหมาย 2–3 รอบหลัง คลัง และ diary ล่าสุด
   และตรวจชุดที่ agent จัดด้วยกฎที่มีแหล่งอ้างอิง (คู่ห้ามผสม จำนวนสารต่อถัง การสลับกลุ่ม ลำดับเท)
3. **runbook การจัดยา** ถ้าเจ้าของเห็นว่าจำเป็น

## Acceptance

- จากประวัติจริง agent บอกได้ว่ารอบก่อนพ่นกลุ่มไหน และชุดที่เสนอผ่านกฎทุกข้อพร้อมเหตุผล
- ชุดที่ฝ่ากฎถูกโค้ดปฏิเสธพร้อมชื่อกฎและแหล่งอ้างอิง
- ช่องที่ agent เติมจากฉลากติดป้ายจนเจ้าของยืนยัน
