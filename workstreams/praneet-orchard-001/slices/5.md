# 5. คลังยา การพ่น รอบการผลิต การจัดยาตามกลุ่ม และ diary

**ทำไม:** เจ้าของจัดยาให้ถูกโดยไม่เปิดตำราไม่ได้ งานนี้ต้องการประวัติการพ่นตามกลุ่มยาและคลังที่เป็นปัจจุบัน

1. **praneet-web:**
   - คลังยา: ชื่อการค้า สารออกฤทธิ์และกลุ่มของแต่ละตัว สูตรฟอร์มูเลชัน (WP / SC / SL / EC) ขนาด ราคา
     มี / เหลือน้อย / หมด และของที่ซื้อเพิ่ม ใช้ชุดเดียวกับบันทึกการดูแลของแปลงพันธุ์ไม้
   - การพ่นในสวนผลไม้: แปลง วิธี ถัง ยาที่ใช้จริงพร้อมอัตรา **ระยะใบตอนพ่น** สิ่งที่เจอ วันนัดตรวจ ผลที่ตรวจ
     ระยะใบบันทึกตอนพ่น (และใน diary ได้) ไม่ต้องออกไปสำรวจ
   - **ใส่ปุ๋ยทางดิน (revision 0.6):** ฟอร์มของตัวเอง แยกจากพ่นยา ("งานคนละอย่าง ใส่ปุ๋ย กับพ่นยา")
     ตัดจากคลังเดียวกัน กฎผสมยาและการสลับกลุ่มใช้กับการพ่นเท่านั้น
   - รอบการผลิตของแต่ละแปลง นับวันจากวันแตกใบอ่อนเพื่อบอกระยะที่น่าจะเป็น เมื่อมีตัวเลขจากแหล่งที่ตรวจได้
   - สิ่งที่เจอในสวน: ปุ่มของที่เจอบ่อยกับระดับ น้อย / กลาง / มาก และพิมพ์เองได้ แบบเดียวกับชนิดงานใน slice 2
   - diary ส่วนตัว เก็บตามคำพูด เลือกแปลงได้ บอกว่าใครบันทึก ไม่ขึ้นปฏิทิน
2. **praneet-office:** คำสั่งรวมประวัติกลุ่มยาของแปลงเป้าหมาย คลัง สิ่งที่เจอ และ diary ล่าสุด
   และตรวจชุดที่ agent จัดด้วยกฎที่มีแหล่งอ้างอิง
   - เริ่มจากผลตรวจ 16 ข้อ (`.assets/orchard-decision/chemical-rules-report-20261027.md`, git ไม่ track)
     ข้อที่ไม่มีแหล่งไม่บังคับ ข้อที่ระบุว่ามาจากสรุปผลค้นหาต้องอ่านแหล่งตรงก่อนบังคับ
   - ฉลากยาชนะกฎทั่วไปเสมอ กลุ่มยาคำนวณจากสารออกฤทธิ์ ไม่ใช้กลุ่มที่พิมพ์ไว้ใน Sheet
   - ประวัติที่ใช้ตรวจการสลับกลุ่ม: อย่างน้อย 60 วันและทั้งรอบการผลิต
   - จำนวนสารต่อถังไม่มีแหล่งรองรับ ถ้าจะกำหนดเป็นค่าที่เจ้าของเลือก
3. **runbook การจัดยา** ถ้าเจ้าของเห็นว่าจำเป็น

## Acceptance

- จากประวัติจริง agent บอกได้ว่ารอบก่อนพ่นกลุ่มไหน และชุดที่เสนอผ่านกฎทุกข้อพร้อมเหตุผล
- ชุดที่ฝ่ากฎถูกโค้ดปฏิเสธพร้อมชื่อกฎและแหล่งอ้างอิง
- ช่องที่ agent เติมจากฉลากติดป้ายจนเจ้าของยืนยัน
