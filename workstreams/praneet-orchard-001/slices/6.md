# 6. การพ่นและประวัติกลุ่มยา

**ทำไม:** การสลับกลุ่มต้องรู้ว่ารอบก่อนพ่นกลุ่มไหน จากประวัติจริงของแต่ละแปลง (revision 0.8)

1. **praneet-web:** งานพ่นยาและใส่ปุ๋ยในงานรายวันมีรายละเอียดเพิ่ม ไม่บังคับ บันทึกครั้งเดียว
   ("บันทึกทีเดียวดีสุด แล้วใช้ด้วยกันได้")
   - ยาจากคลังของ slice 5 พร้อมอัตรา ขนาดถัง และลำดับที่ใส่
   - **คัดลอกยาได้จากสูตรเก่า หรือจากรอบพ่นล่าสุดของแปลงนั้น** แล้วแก้ก่อนบันทึก (revision 0.9)
   - **ระยะใบตอนพ่น:** เลือก ใบอ่อน / เพสลาด / ใบแก่ / ออกดอก / ติดผล หรือพิมพ์เอง
   - ใส่ปุ๋ยทางดินตัดจากคลังเดียวกัน กฎผสมยาและการสลับกลุ่มใช้กับการพ่นเท่านั้น (revision 0.6)
   - ชื่อยาและอัตราไม่ขึ้นปฏิทิน event ยังเขียนงานตามคำของเจ้าของเหมือนเดิม
   - บันทึกการดูแลของแปลงพันธุ์ไม้เลือกยาจากคลังเดียวกันแทนการพิมพ์ชื่อใหม่
     ทำขนานกับ `praneet-nursery-001` ได้ (revision 0.9)
2. **นำเข้า `Treatment_Logs` 38 ครั้ง** จาก Sheet ซ้ำได้ ผูกกับแปลงและสูตรเก่าตามเลข `RCP`
   กลุ่มคิดจากยาในสูตรที่ตรงกับยาบนชั้น ยาที่ไม่ตรงบอกว่าไม่รู้กลุ่ม ไม่ใช้กลุ่มที่พิมพ์ใน Sheet
   ข้อความเดิมเก็บไว้ทุกแถว ผูก lot ให้งานพ่นวันที่ 2026-10-28 ที่เจ้าของเลื่อนมา slice นี้ (revision 0.9)
3. **praneet-office:** คำสั่งบอกประวัติกลุ่มยาของแปลง อย่างน้อย 60 วันย้อนหลัง พร้อมระยะใบ
   และ diary ช่วงเดียวกัน `orchard add` บันทึกงานพ่นพร้อมรายละเอียดยาตามที่เจ้าของเล่า
   แสดงก่อนเขียนเสมอ และ agent แปลงงานพ่นที่บันทึกเป็นโน้ตก่อนมีฟอร์ม (28 และ 29 ต.ค.)
   เป็นรายละเอียดครั้งเดียว เมื่อชั้นยามียาเหล่านั้นแล้ว (revision 0.9)

## Acceptance

- จากประวัติจริง agent บอกได้ว่ารอบก่อนพ่นกลุ่มไหนในแต่ละแปลง
- งานพ่นที่ไม่ใส่รายละเอียดยายังบันทึกและคิดค่าแรงได้เหมือนเดิม
- event ในปฏิทินไม่มีชื่อยา อัตรา หรือเงิน
- นำเข้าไฟล์เดิมซ้ำแล้วไม่เปลี่ยนอะไร
- งานพ่นที่คัดลอกจากสูตรหรือรอบก่อน แก้ได้ก่อนบันทึก และไม่แก้สูตรต้นทาง
