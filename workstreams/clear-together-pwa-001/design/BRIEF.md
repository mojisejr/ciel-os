# Design brief — เคลียร์กัน (ชื่อชั่วคราว)

เจ้าของยอมรับภาพรวม mockup และสีฟ้าพาสเทลก่อนเปิด workstream
source อ้างอิงคือ [mockup.html](mockup.html); เป็น HTML fragment สำหรับ visualization
runtime เดิม ไม่ใช่ production app หรือ standalone PWA

## Visual direction

ฟ้าพาสเทลเป็นสีหลัก มิ้นต์สำหรับจ่ายแล้ว พีชสำหรับปุ่มส่งบิลและสถานะรอจ่าย
พื้นกระดาษเกือบขาว ข้อความเข้ม อ่านยอดได้เร็ว ไม่ใช้สีเป็นเครื่องบอกสถานะเพียงอย่างเดียว

- IBM Plex Sans Thai 400/500; ตรวจ readability และ contrast ในแอปจริง
- Panels โค้งประมาณ 24 px ปุ่มหลักกดง่าย ยอดเงินใช้ tabular numbers
- รองรับหน้าจอมือถือ; ความโค้งกรอบ mockup ไม่ใช่ข้อกำหนดให้มีกรอบโทรศัพท์ในแอปจริง

## Screens and interaction

- หน้ารวม: ยอดรอจ่าย ยอดจ่ายแล้ว รายการพร้อมสถานะ และตัวกรอง
- คนเบิก: ชื่อรายการ ยอด รูปบิล และ note → ส่งบิล
- รายละเอียด: รูปบิล note ยอด และ timeline
- คนจ่าย: แนบสลิป note → mark จ่าย → ดูหลักฐานย้อนหลัง
- Mockup มี “สมุดบิล” และ “กล่องบิล”; ยังไม่มีการยืนยันเลือก layout เดียว
  แนะนำเริ่ม implementation จากกล่องบิลแล้วให้เจ้าของตรวจ

## Prototype boundaries

ข้อมูลทั้งหมดเป็นตัวอย่าง บิลและสลิปเป็นภาพจำลอง ปุ่มแนบรูปไม่ได้อัปโหลดไฟล์จริง
ปุ่มสลับคนเบิก/คนจ่ายใช้ดูหน้าจอเท่านั้น ไม่ใช่การกำหนดสิทธิ์ของระบบจริง
mockup ไม่พิสูจน์ auth, database, file privacy หรือ offline behavior

ก่อนเปิด workstream ได้ตรวจ prototype flow ส่งบิล/จ่ายบิล การรักษาค่าในฟอร์ม
และความกว้าง 736/390/352 px โดยไม่พบ JS error หรือ overflow
การทดสอบ production flow เป็นงานใหม่ใน slice 2 และ 3 ของแผน

## Confirmed implementation direction after syncup

ผู้ใช้คือเจ้าของกับแฟนสองคน ทั้งคู่ส่งบิลให้อีกคนจ่ายได้ตามแต่ละรายการ
หน้าจอจริงแยก “เราต้องจ่าย” กับ “รออีกคนจ่าย” ตาม session และไม่หักกลบยอดอัตโนมัติ
เลือกหลายบิลในทิศทางเดียวกันเพื่อจ่ายด้วยหนึ่งสลิปได้; แสดงยอดรวมก่อนยืนยัน
แก้/ยกเลิกบิลรอจ่าย และย้อนชุดการจ่ายพร้อมเหตุผลโดยเก็บประวัติเดิม
หน้าส่งบิล/สลิปบีบอัดภาพก่อนส่งและมี preview ตรวจความอ่านได้
แสดงข้อจำกัด/การใช้พื้นที่ให้เข้าใจง่าย เมื่อเต็มหยุดอัปโหลดแทนการเพิ่มค่าใช้จ่าย
ไม่มีหน้าสมัครสมาชิก; ข้อกำหนดนี้เป็นทิศทางสำหรับแอปจริง ไม่ได้อ้างว่า mockup เดิมทำครบแล้ว
