# 3. Prove a second character through the shared workflow

## Scope

Build a meaningfully different head-large, plump human collectible from an
owner-approved reference, using the shared contract/runbook and common review
tools. Select the second figure with the owner; do not silently choose a page
mascot. Reuse approved reference evidence from slice 2 and exercise supplied-ref
entry behavior without requiring image generation again.

## Acceptance

- Common workflow/reviewer runs against the baseline and the second character
  through data-selected paths and identity metadata. Character-specific shape
  code is permitted and identified; supported parameters are documented honestly.
- Develop primary head/hood/body/outfit masses together and internally inspect
  equal-scale front, both obliques/sides, back, silhouette and 360-degree views.
  Escalate material ref/identity conflicts rather than guessing silently.
- Deliver source and .blend/GLB, approved ref/brief, review sheets and a silent
  ten-second turntable with standard foot origin/front direction/scale notes.
  Verify actual files, loadability, media streams, hashes and retained assets.
- Owner reviews the final shape. Mechanical symmetry/manifold/stream checks
  alone do not establish visual quality or reference likeness.
- Record attempts, measured rendering resources and known/unknown cost. No
  unapproved paid generation, map scene, animation rig, printing preparation,
  upload, publishing or course separation.
- Test the reusable asset/review path from the intended second client when an
  actual client run is available. Otherwise explicitly leave that proof open;
  shared command names do not count as successful Claude execution.

## Delivery boundary

Closeout identifies the two character packages, both entry-path evidence,
owner art decisions and any remaining interoperability or asset-retention gap.
No universal image-to-3D, automatic one-shot likeness, zero total cost or viral
performance claim follows from these two characters.
