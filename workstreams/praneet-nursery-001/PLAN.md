## Goal and owner agreement

ปราณีต (เจ๊ฟัก) พันธุ์ไม้ จันทบุรี เปิดมากว่า 30 ปี รอลูกค้าเข้าร้านมาตลอดและไม่เคยขายออนไลน์
ปีที่แล้วขายไม่ค่อยออก ลูกค้าเก่าเหลือไม่กี่ราย ติดต่อทางโทรศัพท์ทั้งหมด
และคนงานเก่าที่ออกไปแล้วเอาเบอร์ลูกค้าไปให้ร้านอื่น เจ้าของต้องการ transform ร้านให้เป็นระบบ
งานนี้เป็นส่วนขยายของธุรกิจที่มีอยู่แล้ว และเป็นคนละโปรเจคกับ MuMate

เจ้าของยืนยันใน syncup วันที่ 2026-10-08 ดังนี้

- **สินค้า:** หมอนทองเป็นหลัก ทั้งหมดเสียบยอดเอง (ยอดมาจากหลายสวน) ลงถุงเบอร์ 9 (4.5 × 12 นิ้ว)
  กำลังผลิตสูงสุด 30,000 ต้นต่อปี ตอนนี้มี 3–4 lot รวมประมาณ 12,000 ต้น
- **lot:** คือชุดต้นที่ลงถุงเพาะชำวันเดียวกัน อายุนับเป็นเดือนจากวันลงถุง
  ปีหนึ่งลงได้หลายชุด และแต่ละชุดมีจำนวนไม่เท่ากัน
- **สิ่งที่ลูกค้าดู:** ความสูง อายุ และทรง ใน lot เดียวกันมีทั้งยอดกระโดงและยอดข้างปนกัน
  ยอดกระโดงแพงกว่าประมาณ 10–20 บาทต่อต้น
- **พร้อมขาย:** ต้องสูง 50 ซม. ขึ้นไป และ **เจ้าของเป็นคนประกาศ** ระบบไม่เปลี่ยนสถานะเอง
- **ลูกค้า:** คนซื้อไปขายต่อ หรือซื้อไปปลูกจำนวนมาก ขายเป็นชุดละ 100 ต้นขึ้นไป
  ส่งได้สองแบบเท่านั้น คือ **roll pallet** และ **รถคอก** ไม่ส่งเป็นกล่อง
  ราคาต้นตั้งตามขนาด บวกค่าส่งตามจริงเป็นบรรทัดแยก
- **จุดต่าง:** timeline ของแต่ละ lot ให้ลูกค้าเห็นของจริงโดยไม่ต้องมาที่ร้าน
  เปิดให้ทุกคนดูและแชร์ได้แบบอ่านอย่างเดียว
- **ลูกค้าเป็นของร้าน:** คุยกับลูกค้าผ่าน LINE OA ของร้านเท่านั้น
- **ระบบเวอร์ชันแรก:** กระดาน lot แบบสาธารณะ, LINE OA ที่เจ้าของตอบแชตเอง, และ rich menu
  ต้องมีหลังบ้านตั้งแต่แรก ให้เจ้าของอัปเดตข้อมูลเอง และให้ agent เข้าถึงข้อมูลเพื่อช่วยจัดการ
  เก็บข้อมูล และดึงมาวิเคราะห์ด้วยกัน ออเดอร์ การจ่ายเงิน และการติดตามรถ
  เก็บในหลังบ้านไปก่อน แล้วค่อยย้ายเข้า LIFF หลังขายรถคันแรกได้
- **การหาลูกค้า:** เริ่มจากวิธีที่ไม่มีค่าใช้จ่าย agent รวบรวมรายชื่อร้านต้นไม้ในจังหวัดเป้าหมาย
  แล้วพาเจ้าของทักไปพร้อมลิงก์กระดาน และโพสต์ในกลุ่ม Facebook
  ถ้าจำเป็นต้องโฆษณาจริง งบไม่เกิน 1,000 บาทต่อเดือน และต้องวัดผลได้ชัด
- **รับประกัน:** ดูเป็นเคส ๆ ให้ลูกค้าพอใจ โดยร้านไม่เสียหายเกินจำเป็น ไม่ประกาศเป็นนโยบาย
- **ทีม:** เจ้าของและ agent คนวัดต้นส่วนใหญ่คือเจ้าของ agent ดูแลเว็บ หลังบ้าน stock
  ฐานข้อมูล และ deploy เจ้าของตัดสินเรื่องเงิน ราคา production และสถานะพร้อมขาย
- **โครงระบบ:** แบบเดียวกับ MuMate คือ repo ระบบแยกจาก repo office
  จะใช้ DigitalOcean หรือ Vercel ค่อยตัดสินตอนเริ่ม slice 2
- **วัดผล:** เป้าเริ่มต้นคือประมาณ 3,000 ต้น หรือรถ 2–3 คัน ผ่านช่องทางใหม่ ก่อนสิ้นฤดูฝนปี 2027
  แล้วดูตัวเลขจริงเพื่อปรับกลยุทธ์ไปเรื่อย ๆ ร่วมกัน
- **ยังไม่ทำ:** การจองพร้อมมัดจำ และ "ให้ปราณีตช่วยหา" (หาพันธุ์ที่ร้านไม่มีจากสวนพันธมิตร
  โดยร้านรับรองคุณภาพ) แต่ข้อมูลต้องเผื่อช่องที่มาของต้นไว้ตั้งแต่แรก
- **เริ่มเมื่อไร:** เจ้าของสั่งให้เริ่มทันที ไม่ต้องรอ MuMate และไม่ต้องรอ office

## Scope, invariants and constraints

- ลูกค้าติดต่อร้านผ่าน LINE OA ของร้านเท่านั้น
- รายชื่อลูกค้าอยู่ในฐานข้อมูลที่เจ้าของและ agent เข้าถึงได้เท่านั้น
  ไม่มีข้อมูลลูกค้าใน git และไม่มีในไฟล์ที่แชร์ออกไป

- การสร้าง repo การสร้างบัญชี LINE OA/channel และการ deploy production
  เป็นการกระทำออกไปข้างนอก ต้องให้เจ้าของสั่งตาม slice
- งาน child repo ใช้ topic branch และ PR ให้เจ้าของ merge
- งานใน HQ ใช้ standing branch ปัจจุบัน และ commit เฉพาะไฟล์ของ workstream นี้
