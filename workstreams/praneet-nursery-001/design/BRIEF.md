# ปราณีต พันธุ์ไม้ — design brief

เจ้าของยอมรับ [mockup](mockup.html) เวอร์ชัน 3 เมื่อ 2026-10-08 ("เยี่ยมเอาตามนี้")
brief นี้แปลง mockup เป็นเกณฑ์ที่ตรวจได้ และจะย้ายไปเป็น `DESIGN.md` ใน repo ระบบตอน slice 3

## ภาพรวม

หน้าสินค้าแบบ apple.com ในแบบชาวสวน: รูปแปลงจริงเป็นตัวเด่น หัวข้อใหญ่ ข้อความน้อย
ตัวเลขของ lot วางแบบหน้าสเปก ความพรีเมียมมาจากความชัดเจนและมาตรฐาน ไม่ได้มาจากของตกแต่ง

- **ตัวตนของร้าน:** รูปวาดหน้าหนวด (ภาพเดียวกับ Takai) คู่ชื่อ "ร้านตาหนวด · ปราณีต พันธุ์ไม้"
  และบรรทัด "ตั้งแต่ พ.ศ. 2535 · วันนี้ดูแลโดยหนวด"
- **โทนสี:** ใบทุเรียน (ด้านบนเขียวเข้ม ใต้ใบสีทองแดง) ในแสงแดดยามบ่าย
  พื้นขาวอุ่น แสงสีทองจาง ๆ ปุ่มสีเขียวใบเข้ม ค่าสีทั้งหมดอยู่ใน `:root` ของ mockup
- **ตัวอักษร:** Anuphan สำหรับหัวข้อ (น้ำหนัก 600) และ IBM Plex Sans Thai สำหรับเนื้อหา
  ตัวเลขใช้ tabular-nums
- **พื้นผิว:** การ์ดใช้เงาบางแทนเส้นขอบ มุมโค้ง 18–24 px
  แสงพื้นหลังเป็นของทั้งหน้า ห้ามมีขอบกล่องตัด (เจ้าของทักเรื่องนี้ในเวอร์ชัน 2)
- **โหมดมืด:** เขียวป่ายามค่ำกับแสงทองอุ่น ใช้ token ชุดเดียวกัน

## หน้าจอ

## เกณฑ์ที่ต้องผ่าน

**Mobile first และ responsive ทุกจอ**
- ออกแบบและเขียน CSS เริ่มจากจอมือถือ แล้วค่อยขยายขึ้น
- ตรวจที่ความกว้าง 360, 390, 430, 768, 1024 และ 1440 px ทุกหน้า
  - ไม่มี scroll แนวนอน
  - ไม่มีข้อความถูกตัด
  - ขอบข้างอย่างน้อย 16 px
- รองรับ safe-area ของ iPhone และใช้ `dvh` แทน `vh` กับส่วนที่สูงเต็มจอ

**อ่านง่ายและกดง่าย**
- ความคมชัดของสีผ่าน WCAG AA ทั้งโหมดสว่างและโหมดมืด
  ตัวอักษรปกติอย่างน้อย 4.5:1 ตัวใหญ่และไอคอนอย่างน้อย 3:1
- เนื้อหาอย่างน้อย 16 px ป้ายกำกับอย่างน้อย 13 px
- ช่องกรอกอย่างน้อย 16 px เพื่อไม่ให้ iOS ซูมเองตอนแตะ
- ปุ่มและจุดกดอย่างน้อย 44 × 44 px ส่วนหน้าบันทึกผลวัดใช้ 56 px เพราะใช้กลางแปลงด้วยมือเดียว
- ตรวจด้วย axe แล้วไม่มีปัญหาระดับ critical หรือ serious ทุกหน้า

**LINE in-app browser**
- ลูกค้าส่วนใหญ่จะเปิดลิงก์จากแชต LINE ทุกหน้าต้องใช้งานได้ใน in-app browser ของ LINE
  ทั้งบน Android และ iPhone:
  - layout
  - ฟอนต์
  - ต้นตัวอย่างหมุนดู
  - กราฟ
  - ปุ่มทัก LINE
- หลังบ้านใช้ username + password ซึ่งใช้ใน in-app browser ได้
  passkey ยังไม่ได้ยืนยันว่าใช้ใน LINE ได้ ต้องลองก่อนเปิดใช้
- การเลือกรูปและถ่ายรูปในหน้าบันทึกผลวัดต้องทดสอบใน LINE บน Android จริง
- ถ้าความสามารถไหนใช้ใน LINE ไม่ได้ ให้มีทางออกไปเปิดในเบราว์เซอร์ภายนอก
  (พารามิเตอร์ `openExternalBrowser=1` ของ LINE) ห้ามให้หน้าค้างหรือว่างเปล่า
- ภาพตัวอย่างลิงก์ (Open Graph) ต้องขึ้นถูกต้องเมื่อแชร์ในแชต LINE

**ต้นตัวอย่าง 3D บนมือถือ**
- หมุนด้วยนิ้วได้บนมือถือ ทั้งในเบราว์เซอร์ปกติและใน LINE
  ขณะลากหมุนต้องไม่ทำให้หน้าเลื่อนขึ้นลงจนใช้ไม่ได้
- **งบไฟล์:** โมเดล 3D หลังบีบอัดไม่เกิน 5 MB ภาพหมุน 360° รวมไม่เกิน 3 MB
  ต้องโหลดเสร็จและหมุนได้ลื่นบน Android ระดับกลาง
- **ทางสำรองตามลำดับ:**
  - ถ้าเครื่องไม่รองรับ 3D (WebGL) ให้แสดงภาพหมุน 360°
  - ถ้าไม่มีภาพหมุน ให้แสดงรูปไม้เมตร
- AR (ตั้งต้นไม้บนพื้นจริง) เป็นของแถม ไม่บังคับ และไม่คาดหวังว่าจะใช้ได้ใน LINE
- ไม่ย้อนกลับไปใช้ภาพจำลองที่โค้ดวาดขึ้น ภาพจำลองใน mockup มีไว้แสดงการใช้งานเท่านั้น

**ความเคลื่อนไหว**
- เคารพ `prefers-reduced-motion` เช่น ต้นตัวอย่างจะไม่หมุนเองเมื่อผู้ใช้ปิดการเคลื่อนไหว

## ห้ามมี

- การเร่งให้รีบซื้อแบบปลอม ๆ
- รูปจากคลังภาพ
- รีวิวที่ไม่ได้มาจากลูกค้าจริง
- ป๊อปอัป
- ชื่อคนงานหรือชื่อลูกค้า
- ตัวเลขต้นที่คัดทิ้ง (ร้านคัดทุกครั้งตอนขาย)
- คำสัญญาบริการหลังการขาย จนกว่าเจ้าของจะตัดสินหลังขายได้จริง
