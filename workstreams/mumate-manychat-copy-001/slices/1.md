# Slice 1 — ข้อความแรกและภาพตัวอย่างใน flow จริง

## Scope

- Duplicate flow "Bazi E-Book 95" เป็น backup 1 ชุด และตรวจว่า trigger ของ backup ปิดทุกตัว
  แล้วหยุดรายงานเจ้าของ
- ใน draft ของ flow จริง: เปลี่ยนข้อความแรกเป็นแบบ A, ในกล่อง "2a ตัวอย่าง+รีวิว" เดิม
  เปลี่ยน carousel เป็น Image block 4 อันตามลำดับในแผน, แก้ข้อความนำก่อนภาพ
  และย้ายคำรีวิวไปไว้ในข้อความ "✍️ เขียนโดย"
- Preview draft เข้า Messenger ของเจ้าของ แล้วตรวจบนมือถือ
- เมื่อเจ้าของสั่ง กด Publish, เจ้าของทัก "Bazi" เช็กหนึ่งรอบ และเคลียร์ tag ที่ติดจากการทดสอบ

## Acceptance

- บนมือถือของเจ้าของ ข้อความแรกขึ้นครบ ปุ่ม 3 ปุ่มพาไปที่เดิม
- กด 📖 ดูตัวอย่างข้างใน แล้วได้ภาพ 4 ภาพตามลำดับ ทุกภาพเห็นทั้งหน้า กดแล้วขยายเต็มจอได้
- flow จริงหลัง Publish: trigger, keyword, tag, field และ step อื่นเหมือน export ของ 2026-11-08
  ต่างกันแค่ข้อความแรก step 2a และตัวเลขสถิติ กล่อง 2a ยังเป็นกล่องเดิม
- backup อยู่ใน ManyChat และ trigger ของ backup ปิดทุกตัว closeout บันทึกชื่อ backup นั้น
- บัญชีเจ้าของไม่มี tag ที่ติดจากการทดสอบเหลืออยู่
