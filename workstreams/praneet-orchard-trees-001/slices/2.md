# 2. ต้นในงาน และหน้าต้นในสวน

1. **praneet-web, ข้อมูล:** ตารางต้นและงานกับต้น ทุกการเพิ่ม เปลี่ยนชื่อ และเอาออก เก็บใน audit
2. **ฟอร์มและหน้างาน:** ส่วน "รายต้น" ปิดไว้ก่อน พิมพ์ชื่อ ค้นและแตะเลือกต้นที่มี ชื่อใหม่เป็นต้นใหม่
   แก้งานเก่าแล้วใส่ต้นได้ หน้างานบอกต้นที่ทำและลิงก์ไปหน้าต้น ไม่มีใน P-4
3. **หน้าต้นในสวน:** แปลง → ต้นในแปลง (ค้นหา เรียงเลขแบบคนอ่าน งานล่าสุด) → หน้าต้น (ทุกงาน เปลี่ยนชื่อ)
4. **ปฏิทิน:** event ของงานที่มีต้นต่อท้ายชื่อต้น

## Acceptance

- test ของ praneet-web: ต้นใหม่จากฟอร์ม ชื่อซ้ำในแปลงไม่สร้างต้นซ้ำ งานใส่ได้เฉพาะต้นของแปลงตัวเอง
  งานที่ซ่อนไม่ขึ้นในหน้าต้น เรียงเลขแบบคนอ่าน หน้าอ่านได้ไม่ตัดคำที่ 360 รันใต้ตัวคุมหน่วยความจำ
- หลัง merge เจ้าของบันทึกงานจริงพร้อมต้นบนมือถือ และเห็นในหน้าต้นและในปฏิทิน
