# 4. ช่วงชีวิตและอายุของต้น

1. **praneet-web:** "ต้นนี้ตาย/โค่นแล้ว" พร้อมวันที่และบันทึกสั้น เป็นเส้นคั่นในประวัติ ไม่ใช่งาน
   ต้นที่ตายจางในรายชื่อและไม่ขึ้นในฟอร์ม ปลูกใหม่สองทาง: ต้นเดิมต่อ หรือต้นใหม่ปลูกแทนที่ลิงก์ถึงกัน
   ระบบไม่ปิดกล่องเอง เอาคืนได้ถ้ากดผิด
2. **อายุ:** "ปลูกเมื่อ" ไม่บังคับ วันที่หรือปี พ.ศ. ใส่ภายหลังได้ ปลูกใหม่ใช้วันปลูก หน้าต้นบอก "อายุราว X ปี"

## Acceptance

- test ของ praneet-web: ต้นที่ตายไม่ขึ้นในฟอร์ม ปลูกใหม่ต้นเดิมแล้วประวัติเดียวและอายุนับใหม่
  ปลูกแทนแล้วลิงก์สองทาง อายุจากปีอย่างเดียวถูก รันใต้ตัวคุมหน่วยความจำ
- เจ้าของลองบันทึกต้นตายและปลูกใหม่บนมือถือ
