## เป้าหมายและข้อตกลงกับเจ้าของ (syncup 3 รอบ, 2026-11-04, เดาตรง 14.5/20)

เจ้าของมองว่าการดูแลรายแปลงครบแล้ว และอยากต่อยอดเป็นรายต้น โดยไม่ต้องให้ผู้ใช้นับและลงต้นทุกต้นตั้งแต่วันแรก
ต้นเข้าระบบทีละต้นตอนบันทึกงาน ปริ้นป้ายไปแปะทีละชุด "จนเต็มในวันนึงโดยไม่รู้ตัว" และบันทึกยังเป็นงานเหมือนเดิม

- **ต้นเข้าระบบจากงาน:** ฟอร์มเพิ่มงานมีส่วน "รายต้น" ปิดไว้ก่อน พิมพ์ชื่อหรือเลขต้นอะไรก็ได้ ใส่ได้หลายต้น
  ชื่อที่ยังไม่มีเป็นต้นใหม่ของแปลงนั้น ชื่อไม่ซ้ำในแปลงเดียวกัน ระบบไม่เดาจากชื่องาน
  แก้งานเก่าแล้วใส่ต้นได้ แปลงพันธุ์ไม้ P-4 ใช้ lot แบบเดิม ไม่มีรายต้น
- **ค้นหา:** ช่องเดียว จับบางส่วนของชื่อ เรียงเลขแบบคนอ่าน (2 ก่อน 10) ใช้ในรายชื่อต้นและในฟอร์ม
- **หน้าใหม่ "ต้นในสวน":** แปลง → ต้นในแปลง → หน้าต้น (ทุกงานของต้นนั้น เปลี่ยนชื่อ ตั้งกล่อง) → หน้างาน
  → คนงานและเงินเหมือนเดิม หน้างานบอกต้นที่ทำและลิงก์ไปหน้าต้น
- **กล่องของต้น:** เรื่องเดียวของต้นเดียว รับเฉพาะงานที่มีต้นนั้น ขึ้นหน้าวันนี้และเรียงแบบเดียวกับกล่องแปลง
  งานเดียวหลายต้นใส่ได้หลายกล่อง หรือใช้กล่องของแปลงเป็นหลักก็ได้ ผู้ใช้เลือกเอง
- **ช่วงชีวิต:** หน้าต้นมี "ต้นนี้ตาย/โค่นแล้ว" พร้อมวันที่และบันทึกสั้น เป็นเส้นคั่นในประวัติ ไม่ใช่งาน
  ค่าแรงโค่นบันทึกเป็นงานตามปกติ ต้นที่ตายจางในรายชื่อและไม่ขึ้นในฟอร์ม ปลูกใหม่ผู้ใช้เลือกเอง:
  ใช้ต้นเดิมต่อ (ประวัติเดียว อายุนับใหม่) หรือต้นใหม่ "ปลูกแทน" ที่ลิงก์ถึงกันสองทาง ระบบไม่ปิดกล่องเอง
- **อายุ:** "ปลูกเมื่อ" ไม่บังคับ ใส่วันที่หรือแค่ปี พ.ศ. ภายหลังได้ หน้าต้นบอก "อายุราว X ปี"
- **ป้าย:** A4 แผ่นละ 3 × 8 ชื่อต้นตัวใหญ่ ชื่อแปลงตัวเล็ก ไม่มี QR ติ๊กเลือกเอง ต้นที่เข้าระบบล่าสุดอยู่บน
  กรอง "เพิ่มตั้งแต่วันที่" ได้ ระบบไม่จำว่าปริ้นแล้ว ("ระบบไม่ต้องจำ ... แม้แต่มี QR ก็เถอะ")
- **ปฏิทิน:** event ต่อท้ายชื่อต้น ยังไม่มีเงินใน event
- **praneet-office:** agent บันทึกงานพร้อมต้นและใส่กล่องของต้นได้ ชื่อต้นไม่ตรงกับที่มี ถามก่อนว่าต้นใหม่หรือต้นเดิม
- **ทำขนาน:** เจ้าของอนุญาตให้ทำพร้อม `praneet-video-posts-001` (Q70) งาน praneet-office ทำใน worktree แยก
  ไม่แตะ checkout ที่ Codex ใช้

## ที่เจ้าของเลือกจากตัวอย่าง (revision 0.2, 2026-11-04)

เจ้าของเลือกตามที่ agent เอนทุกข้อ ("1A 2A 3ตรง ลุยครับ")

- **ส่วนรายต้นในฟอร์ม แบบ A:** พิมพ์แล้วแตะ ขึ้นเฉพาะต้นที่ตรงกับที่พิมพ์ แถว "+ ต้นใหม่" อยู่ในที่เดียวกัน
- **รายชื่อต้นในแปลง แบบ A:** แถว แต่ละแถวบอกงานล่าสุดของต้น หน้าตาเหมือนแถวกล่องติดตาม
- **หน้าที่มีแบบเดียวตรงตามตัวอย่าง:** เลือกแปลง (3 แปลง ไม่มี P-4) หน้าต้น ต้นที่ตายพร้อมปลูกใหม่สองทาง
  หน้าเลือกปริ้นป้าย และแผ่น A4 3 × 8

### โครงข้อมูลที่ยอมรับ

ตารางใหม่ ไม่แตะตารางงานเดิม ทุกการเปลี่ยนเก็บก่อนหลังใน audit เหมือนงาน

| ตาราง | เก็บ | กติกาที่ฐานข้อมูลบังคับ |
|---|---|---|
| ต้น | แปลง ชื่อ วันที่เข้าระบบ ปลูกแทนต้นไหน (ไม่บังคับ) | ชื่อไม่ซ้ำในแปลงเดียวกัน ไม่สนตัวพิมพ์เล็กใหญ่และช่องว่างหัวท้าย ไม่มีต้นใน P-4 |
| ช่วงชีวิตของต้น | ปลูก (วันที่ หรือแค่ปี) ตาย โค่น พร้อมวันที่และบันทึกสั้น | อายุนับจากการปลูกครั้งล่าสุด ต้นที่เหตุการณ์ล่าสุดเป็นตายหรือโค่นไม่ขึ้นในฟอร์ม ลบเหตุการณ์ที่กดผิดได้ |
| งานกับต้น | งาน และต้น | ต้นต้องอยู่ในแปลงหนึ่งของงานนั้น งานที่ซ่อนไม่นับในหน้าต้น |
| กล่อง (เดิม) | ช่องต้น ไม่บังคับ | กล่องของต้นรับเฉพาะงานที่มีต้นนั้น กล่องแปลงเดิมนับเหมือนเดิม |

ปฏิทิน: หัวเรื่องของ event ต่อท้ายชื่อต้น เช่น "· ต้น 12, A-3" การตายของต้นไม่ใช่งาน จึงไม่ขึ้นปฏิทิน
