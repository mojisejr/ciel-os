# 1. Closeout card and voice

1. **Repository.** Create private `mojisejr/ciel-office`, seed `main` once,
   clone it to `/Users/non/ghq/github.com/mojisejr/ciel-office`, and register
   `projects/ciel-office/project.yaml` in CIEL with its local binding.
2. **Office code** (Bun, TypeScript) on a topic branch with a draft PR:
   - `office scan`: the scan, card, voice and log described in the plan;
   - `office scan --dry-run`: prints the cards and sentences, sends nothing,
     records nothing;
   - the LaunchAgent file with the ciel-os path as its one setting;
   - a runbook: install, the webhook file, and the plan's three
     removal levels with their check.
3. **Tests** on copies of real closeouts from `ciel-os`, with fake `say`, `gh`
   and webhook:
   - the first run announces nothing and records every closeout as seen;
   - a new closeout is announced once; a second run and an amended commit
     announce nothing;
   - both `done` and `completed`, and both acceptance fields, are read;
   - every URL on the card appears verbatim in the event;
   - Discord, `gh` and unreadable-event failures each give the result the plan
     names;
   - five new closeouts in one run give three cards and "+2 more";
   - a scan leaves every file under the test repository's `.git` unchanged.
4. **Install.** The owner has written the webhook to the env file. The agent
   loads the LaunchAgent under the owner's go of 2026-10-22, after a dogfood
   run against a scratch repository with its own LaunchAgent, removed again
   through removal levels 1 and 2.

Acceptance:

- This slice's own closeout, committed in ciel-os, produces the card on the
  owner's phone and the spoken sentence within about 15 seconds, with no agent
  involved after the commit.
- A closeout committed by a sandboxed agent session is announced the same way.
- Re-running the scan, or a later commit, does not announce it again.
- Removal level 1 silences a test closeout; loading again announces nothing
  old.
- Removal level 2 leaves no office file on the machine except the clone, and
  `launchctl print` reports the label absent.
- The office tests pass; CIEL `bun run check` passes; nothing in `ciel-os`
  outside this workstream and `projects/ciel-office/` changed.
