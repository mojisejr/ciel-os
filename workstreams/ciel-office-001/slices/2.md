# 2. Codex sessions

1. **Verify** what the installed Codex sends to `notify` on a finished turn,
   and whether any event marks a permission wait. Record the payload shape;
   do not assume it.
2. **Adapter** in the office hook entry that maps the Codex payload to the same
   internal shape, so the worker is unchanged.
3. **Rehearse** the `~/.codex/config.toml` change in a scratch `HOME` first,
   then install the `notify` line on the owner's word.

Acceptance:

- A real Codex turn end produces the same card and sentence as a Claude Code
  turn, naming Codex as the client.
- If Codex has no permission-wait event, the runbook says so and no
  substitute is invented.
- Removing the `notify` line restores the previous config byte for byte.
- Tests cover the Codex payload from a recorded sample.
