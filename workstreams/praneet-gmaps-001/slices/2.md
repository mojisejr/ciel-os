# 2. office ส่ง broadcast ได้หลังเจ้าของสั่ง

**ทำไมลำดับนี้:** ไม่ด่วน ระหว่างนี้เจ้าของยังตั้ง broadcast เองใน LINE OA Manager ได้ (API ตั้งเวลาส่งไม่ได้)

1. **praneet-office `bun run line`** เพิ่มคำสั่ง:
   - `broadcast:draft <ไฟล์ร่าง>`: แสดงข้อความและรูป จำนวนเพื่อน โควตาที่จะใช้ และโควตาที่เหลือหลังส่ง
     ถ้าโควตาไม่พอ บอกตรง ๆ และไม่ส่ง
   - `broadcast:test <ไฟล์ร่าง>`: ส่งหาเจ้าของคนเดียว (ใช้โควตา 1) ให้เห็นหน้าตาจริงบนมือถือ
   - `broadcast:send <ไฟล์ร่าง>`: ส่งหาเพื่อนทุกคน รันเมื่อเจ้าของพิมพ์ "ส่ง" ให้ร่างนั้นใน session เท่านั้น
2. **ลิงก์ในข้อความ** ใช้โพสต์ใหม่จาก `posts new` (`/p/F<n>`) เพื่อนับคนเปิด คนกดทัก และออเดอร์
3. ร่างที่ส่งแล้วเก็บไว้ใน office เพื่อดูย้อนหลังว่าครั้งไหนส่งอะไร ไม่เก็บรายชื่อผู้รับ
4. runbook 01 บอกขั้นตอนและข้อห้าม: ไม่ส่งอัตโนมัติ ไม่ส่งรีวิวแลกของ

## Acceptance

- `broadcast:draft` บอกโควตาที่จะใช้ตรงกับ `line check`
- `broadcast:test` ส่งถึง LINE ของเจ้าของ และเจ้าของยืนยันว่าเห็น
- `broadcast:send` ไม่มีทางรันได้โดยไม่ระบุร่าง และ script ไม่พิมพ์ token หรือ user id
