# 1. ออเดอร์จาก Maps มีร่องรอย และลูกค้าที่ได้รับของถูกชวนรีวิว

**ทำไมก่อน:** คนจาก Maps ส่วนใหญ่โทรเข้ามา ไม่ได้ผ่านลิงก์ ถ้าไม่มีที่มา "Google Maps" ยอดขายจาก Maps จะไม่มีร่องรอยในตัวเลขเลย
และรีวิวคือสิ่งแรกที่คนบน Maps ดูก่อนโทร

1. **praneet-web ที่มาของออเดอร์:** เพิ่ม `google_maps` ("Google Maps") ใน `cameFrom` และ check constraint ของ `orders.came_from`
   ด้วย migration แบบเพิ่มอย่างเดียว ข้อมูลเดิมไม่เปลี่ยน
   - รันบน production ขณะ PR ยังเป็น draft แล้วจึงขอ merge
2. **ปุ่ม "รีวิวร้านบน Google" ในหน้า `/me`:** ขึ้นหลังลูกค้ากด "ได้รับของแล้ว" ในออเดอร์ใดออเดอร์หนึ่ง
   ลิงก์เป็นลิงก์ขอรีวิวของโปรไฟล์ที่เจ้าของส่งให้ ลิงก์นี้เป็นข้อมูลสาธารณะ
   ข้อความชวนไม่สัญญารางวัลใด ๆ
3. **runbook ใน praneet-office:** บอกให้ถาม "เห็นร้านจากไหนครับ" ตอนรับสาย และเลือก Google Maps
   บอกวิธีขอรีวิวทีละคนและข้อห้ามเรื่องของแถม
   `orders` แยกยอดตามที่มาได้ ถ้ายังแยกไม่ได้ ให้เพิ่มในรอบนี้

## Acceptance

- ออเดอร์ใหม่เลือกที่มา "Google Maps" ได้บนมือถือ ออเดอร์เดิมไม่เปลี่ยน
- `bun run orders` แสดงยอดของที่มา Google Maps แยกจากที่มาอื่น
- หน้า `/me` ของลูกค้าที่ได้รับของแล้วมีปุ่มรีวิว ลูกค้าที่ยังไม่ได้รับของไม่มี
- test ของ praneet-web ครอบคลุมทั้งสองข้อ และ PR ทั้งสอง repo เจ้าของ merge แล้ว
