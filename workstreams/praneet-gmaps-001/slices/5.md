# 5. ปุ่ม "ออเดอร์ของฉัน" ใน rich menu ตอบลิงก์ /me ในแชต

**ทำไม:** หน้า `/me` เป็นของลูกค้าแต่ละคน (`customers.page_token` ไม่หมดอายุ) แต่ลิงก์ไปถึงลูกค้าได้ทางเดียว
คือเจ้าของคัดลอกจากหลังบ้านไปส่ง ลูกค้าเปิดเองไม่ได้ และ webhook ตอนนี้ไม่ตอบอะไรเลย

1. **rich menu** เพิ่มปุ่ม "ออเดอร์ของฉัน" แบบ postback ข้อมูลคงที่ ไม่มีข้อมูลลูกค้า
   agent ทำภาพเมนูตัวอย่าง 2–3 แบบให้เจ้าของเลือกก่อน (เช่น 5 ช่องแถวเดียว, 2 แถว, รวมปุ่มให้เหลือ 4)
   ขึ้นเมนูจริงด้วย `richmenu:apply` หลังเจ้าของเลือกและบอกให้ขึ้นเท่านั้น
2. **webhook ของ praneet-web** ตอบ postback นั้นด้วย reply message (ไม่นับโควตา):
   - ลูกค้าที่มี `page_token`: ลิงก์ `/me/<token>` ของคนนั้น พร้อมบอกว่าเป็นลิงก์ของเขาคนเดียว
   - ลูกค้าที่ยังไม่มี: บอกว่ายังไม่มีออเดอร์ และบอกวิธีสั่งสั้น ๆ ไม่ออก token ใหม่
   - ตอบเฉพาะ postback นี้ ไม่ตอบข้อความแชต ไม่เก็บข้อความแชต ไม่ push
   - ถ้า LINE ตอบไม่สำเร็จ webhook ยังบันทึกเหตุการณ์และตอบ LINE 200 ตามเดิม การส่งซ้ำของ LINE ไม่ตอบซ้ำ
3. runbook 01 ของ office บอกว่าปุ่มนี้ทำอะไร และลิงก์หลุดแล้วเจ้าของกด "ออกลิงก์ใหม่" ได้เหมือนเดิม

## Acceptance

- กดปุ่มในมือถือจริง (เจ้าของ) ได้ลิงก์ `/me` ของตัวเองในแชต หรือข้อความ "ยังไม่มีออเดอร์" ถ้าไม่มี
- เทสต์ของ praneet-web ครอบ: ลายเซ็นผิดไม่ตอบ, postback อื่นไม่ตอบ, คนมี token ได้ลิงก์ของตัวเองเท่านั้น,
  event ซ้ำ (redelivery หรือ webhookEventId เดิม) ไม่ตอบซ้ำ
- `line check` แสดงเมนูใหม่เป็นค่าเริ่มต้น และเจ้าของเห็นภาพเมนูก่อนขึ้น
- `bun run check` ผ่าน และเจ้าของ merge PR ของทั้งสอง repo แล้ว
