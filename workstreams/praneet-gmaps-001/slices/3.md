# 3. office อ่านตัวเลขจาก Google: gmaps report

**ทำไมท้ายสุด:** ต้องรอ Google อนุมัติ Business Profile API (ไม่เกินราว 14 วันหลังยื่น)
ถ้าไม่อนุมัติ slice 1 และ 2 ยังใช้ได้ครบ

**รอ:** Google อนุมัติ (โควตาไม่เป็น 0) และ Search Console ยืนยัน `ptplant.com` แล้ว

1. **login ครั้งเดียว:** script เปิดหน้า Google ให้เจ้าของกดอนุญาตแบบอ่านอย่างเดียว
   (scope `business.manage` และ `webmasters.readonly`) แล้วเขียน refresh token ลง `.assets/preneet/.env`
   ไม่พิมพ์ค่าออกจอ
2. **`bun run gmaps report [--months n]`** รวมสองแหล่งในหน้าเดียว ภาษาไทยอ่านง่าย:
   - โปรไฟล์ร้าน (Business Profile Performance API): คนเห็นโปรไฟล์ แยก Search/Maps, กดโทร, ขอเส้นทาง,
     กดเข้าเว็บ และคำค้นรายเดือน รวมคำที่มี "ป้า" หรือ "ปราณี" แยกให้เห็น
   - เว็บ (Search Console API): คำค้นที่คนเห็นและกดเข้า `ptplant.com`
   - ลิงก์ Maps ของเรา: คนเปิด กดทัก LINE และออเดอร์ของโพสต์ Maps ผ่าน role อ่านอย่างเดียว
3. **`bun run gmaps check`**: token ใช้ได้ไหม และโควตาเป็นเท่าไร (0 = ยังไม่อนุมัติ)
4. README และ runbook ใหม่ใน office

## Acceptance

- `gmaps check` รายงานโควตาที่ไม่เป็น 0 และ token ใช้ได้
- `gmaps report` แสดงตัวเลขจริงของร้านจากทั้งสองแหล่ง และตัวเลขการกดโทรตรงกับหน้า Performance ในแอปของเจ้าของ
- ไม่มีคำสั่งเขียนไปที่ Google และ script ไม่พิมพ์ token
- PR ของ praneet-office เจ้าของ merge แล้ว
