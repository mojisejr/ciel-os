# 4. ลิงก์โพสต์พาไปหน้าฟีเจอร์ได้

**ทำไม:** โพสต์ที่แนะนำฟีเจอร์ (เช่น "ใส่รถพอไหม") ควรพาคนไปหน้านั้นเลย
ตอนนี้ปลายทางได้แค่ `/` หรือหน้า lot (`lib/posts.ts` และ CHECK ใน `migrations/005_sales.sql`)
F3 ถึง F7 จึงพาไปหน้าแรกแล้วบอกให้แตะปุ่ม

1. **praneet-web:** ปลายทางของโพสต์เพิ่ม `/fit`, `/lots` และหน้าสต็อกแต่ละแถว `/stock/<พันธุ์>/<ถุง>/<ช่วงสูง>`
   ทุกหน้านี้อ่านรหัสโพสต์ผ่าน `visitFrom` อยู่แล้ว ปุ่มทัก LINE จึงพารหัสไปต่อได้
   ไม่รับหน้า `/me` หรือหน้าหลังบ้าน
2. **migration 015** เปลี่ยน CHECK ของ `posts.target_path` ให้ตรงกับกติกาใหม่ แบบเพิ่มอย่างเดียว แถวเดิมยังผ่าน
3. **praneet-office `posts new --target`** รับปลายทางใหม่ และ runbook 05 บอกว่าโพสต์ฟีเจอร์ใช้ปลายทางไหน
4. F3 ถึง F7 ไม่แก้ เพราะข้อความของมันบอกให้แตะปุ่มบนหน้าแรก

## Acceptance

- `posts new --target /fit` สร้างโพสต์ได้ และ `/p/F<n>` พาไป `/fit?p=F<n>` แล้วปุ่มทัก LINE บนหน้านั้นมีรหัสโพสต์
- ปลายทางที่ไม่อยู่ในรายการ (เช่น `/me/...`, `/ops`) ถูกปฏิเสธทั้งที่ API และในฐานข้อมูล
- `bun run check` ของ praneet-web ผ่าน มีเทสต์ใหม่ที่ล้มเมื่อกติกาหลวมเกิน
- เจ้าของรัน migration 015 บน production (ถ้า harness ไม่ให้ agent รัน) และ merge PR ของทั้งสอง repo แล้ว
