# 2. Repeat the workflow and use the first two-week feedback review

## Result and entry

After slice 1 delivery and this slice's owner decision, make the next approved
episode through the same office workflow, and use actual feedback to propose
the following experiment. Reuse working components while keeping the creative
treatment appropriate to the new topic and references.

## Scope

- Exercise a different topic, or a material revision of the first treatment,
  through the same story approval, render, handoff and manual posting loop.
- Fix only repetition problems shown by this use: reusable code, per-episode
  metadata, selective audio reuse and the existing posts runbook/commands.
- Record the owner's observations and available Insights supplied in chat,
  dated and linked to the episode/publication. The agent does the entry. It may
  read accessible public clips and reactions, but has no privileged Insights
  access and must not claim public data is complete.
- Keep the metric name, reporting period, observation date and source with each
  number. A missing value is unknown. Repeated lifetime snapshots update the
  latest value; they do not add new lifetime views to the total each time.
- At the first agreed two-week review, compare episodes of similar age where
  possible. Explain evidence for opening-hook retention, watch time, sharing,
  follows and shop interest only when those measurements are available. Keep
  observations apart from proposed causal explanations.
- Produce a concrete next topic/treatment from that review. Proposed changes
  to the durable page identity or approved budget return to the owner.

## Acceptance / DoD

Cost visibility and Codex/Claude portability requirements are recorded in the
plan's "Recorded cost and client-portability requirements" section (revision
1.6). This decision documents them for later implementation; it does not add
a course, a new tool implementation or a Claude trial to this slice's DoD.

- The next episode is produced and published using the existing workflow; the
  owner does not have to re-explain the page agreement or manually enter a table.
- A revision or unchanged audio reuse is exercised and remains associated with
  the right approved story, final file and F-code when used. Each new delivery
  includes a cover option; an F-link is conditional on a shop destination.
- One two-week review uses identifiable owner/public evidence, states missing
  data and recommends the next experiment. Its lesson is used in a subsequent
  proposal, rather than merely stored.
- Monthly Gemini spending remains inside the approved ceiling. No paid service,
  automated collector, Facebook API or additional video hosting is introduced.
- Applicable code checks and the slice closeout/PR procedure are complete.
