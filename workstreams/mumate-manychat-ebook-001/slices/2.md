# Slice 2 — ตรวจสลิปและส่งของบน staging

## Scope

- ได้รูปสลิป → แอปดาวน์โหลดเก็บไว้เองทันที (ไม่ใช้ลิงก์ของ ManyChat ที่หมดอายุ)
  แล้วส่งตรวจกับบริการตรวจสลิปที่เจ้าของเลือก
- ตรวจ 3 อย่าง: ยอดตรงกับราคาของ env, บัญชีผู้รับเป็นบัญชีบริษัท, สลิปไม่ซ้ำ
  ใช้ทั้งบริการตรวจสลิปและตารางของเราเอง
- ธนาคารยังไม่มีข้อมูล → คิวลองใหม่ตามเวลาที่บริการแนะนำ แล้วบอกลูกค้าว่า "กำลังตรวจ"
- ผ่าน → บันทึกออเดอร์ว่าจ่ายแล้ว → สร้างลิงก์ PDF ที่หมดอายุเอง + โค้ดแอป
  → `setCustomField` + `addTag` paid + `sendFlow` ส่งของ ภายใน 24 ชั่วโมงของลูกค้า
- ไม่ผ่าน → บอกเหตุผลเป็นภาษาคน, ติด tag เหตุผล, แจ้งแอดมินเหมือนทุกวันนี้
- ส่งให้แอดมินเมื่อ: บริการตรวจสลิปล่ม, ลองใหม่ครบแล้วยังไม่ได้, สลิปไม่มี QR
- ลบรูปสลิปตามระยะเวลาที่เจ้าของกำหนด

## Acceptance

- บน staging ทีมโอนจริงตามยอดทดสอบแล้วส่งสลิปใน flow ทดสอบ
  → ได้ลิงก์ PDF และโค้ดในแชท และออเดอร์เป็น paid
- ส่งสลิปเดิมซ้ำ, ยอดผิด, รูปที่ไม่ใช่สลิป → ถูกปฏิเสธพร้อมเหตุผล ไม่ส่งของ และแอดมินได้แจ้ง
- ลิงก์ PDF ใช้ไม่ได้หลังหมดอายุ
- request เดียวกันจาก ManyChat มาซ้ำ → ส่งของครั้งเดียว
- test ครอบทุกกรณีข้างบนโดยใช้คำตอบที่บันทึกไว้ของบริการตรวจสลิป ไม่ยิงบริการจริงตอน test
