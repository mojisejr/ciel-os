# Slice 2 — ตรวจสลิปและส่งของบน staging

## Scope

**รับสลิป**
- ได้รูปสลิปใน flow ทดสอบ → แอปคัดลอกรูปเก็บใน private bucket ของงานนี้ทันที
  แยกโฟลเดอร์ `staging/` กับ `production/` และตามเดือน

**ตรวจสลิป**
- ส่งตรวจที่ Slip2Go `https://connect.slip2go.com/api/verify-slip/qr-image-link/info` ด้วย 3 เงื่อนไข:
  `checkDuplicate`, `checkReceiver` (บัญชีบริษัท) และ `checkAmount` แบบ `eq` กับราคาของ env นั้น (staging ใช้ยอดทดสอบ)
- ตารางของเราเก็บ `transRef` ไม่ให้ซ้ำ เป็นด่านที่สองถัดจาก Slip2Go
- ผ่านเมื่อได้ `200200` เท่านั้น code อื่นแยกตามกลุ่มใน PLAN.md revision 0.3:
  ไม่ผ่าน → บอกลูกค้าและแจ้งแอดมิน · ลองใหม่ได้ → เข้าคิว · `401xxx` → alert ถึงทีม · ไม่รู้จัก → แอดมิน

**ผ่าน**
- บันทึกออเดอร์ว่าจ่ายแล้ว
- สร้างลิงก์ส่วนตัวที่มีอายุจำกัดและจำกัดจำนวนดาวน์โหลด พร้อมโค้ดแอป
- ส่งผ่าน `setCustomField` + `addTag` `bot_paid` + `sendFlow` ภายใน 24 ชั่วโมงของลูกค้า
- PDF ที่ดาวน์โหลดประทับข้อมูลของออเดอร์ทุกหน้า

**ไม่ผ่าน**
- บอกเหตุผลลูกค้าเป็นภาษาคน
- ติด tag เหตุผลที่ขึ้นต้นด้วย `bot_` และแจ้งแอดมินเหมือนทุกวันนี้

**ลบรูป**
- งานตั้งเวลาลบรูปที่เก็บครบ 30 วัน ส่วนผลการตรวจในตารางยังอยู่

**เครื่องมือดูแลใน mumate-infra**
- `env/ebook.env.example` เพิ่ม `SLIP2GO_SECRET_KEY`, ราคา และบัญชีผู้รับ ใส่ค่าจริงด้วย `bin/env-set.sh`
- `bin/ebook.sh orders|pending|resend|mark-paid --reason`
- ทุกคำสั่งมี `--dry-run` และคำสั่งที่เขียนข้อมูลบันทึกเสมอว่าใครสั่งและสั่งเพราะอะไร

## Acceptance

- บน staging tester โอนจริงตามยอดทดสอบแล้วส่งสลิป → ได้ลิงก์และโค้ดในแชท → ออเดอร์เป็น paid
  → `bin/ebook.sh orders` เห็นออเดอร์นั้น
- กรณีที่ต้องถูกปฏิเสธพร้อมเหตุผล ไม่ส่งของ และแจ้งแอดมิน:
  - สลิปเดิมส่งซ้ำ
  - ยอดผิด
  - รูปที่ไม่ใช่สลิป
  - บัญชีผู้รับผิด
- ลิงก์ส่วนตัวใช้ไม่ได้หลังหมดอายุหรือดาวน์โหลดครบจำนวน
  ลิงก์ของ storage ที่ได้จากลิงก์ส่วนตัวหมดอายุในไม่กี่นาที
- request เดียวกันจาก ManyChat มาซ้ำ → ส่งของครั้งเดียว
- รูปอายุเกิน 30 วันถูกลบ ทดสอบด้วยวันที่ปลอม ไม่ต้องรอจริง
- test ครอบทุกกรณีข้างบนด้วยคำตอบของ Slip2Go ที่บันทึกไว้ ไม่ยิงบริการจริงตอน test
  รวมทุก code ใน revision 0.3 และกรณี `200000` ต้องไม่นับว่าผ่าน
