# Slice 4 — ข้อมูลคนจ่ายและไม่จ่าย แล้วเปิดให้ทุกคน

revision 0.6: เจ้าของเลือกทำ metrics ให้เสร็จก่อน แล้วปล่อยทีเดียว การเปิดให้ทุกคนเป็นขั้นสุดท้ายของ slice นี้

## Scope

**เก็บข้อมูล funnel (แอป)**
- ทางรับ event ใหม่ `POST /ebook-api/manychat/event` (secret เดียวกับทางรับสลิป) รับเฉพาะชื่อขั้นที่กำหนดไว้
  และตัวเลือกเหตุผล ตารางเพิ่มใหม่แบบเพิ่มอย่างเดียว ไม่เก็บข้อความแชทที่ลูกค้าพิมพ์
- Caddy: ทางนี้ไม่รอ ตอบทันทีเมื่อแอปล่ม ข้อมูลช่วงนั้นหายได้ แต่ลูกค้าต้องไม่ช้า

**flow จริง (แก้ draft ซ้อมบน staging ก่อน publish ทุกครั้ง publish เมื่อเจ้าของอนุมัติ)**
- ส่ง event จากขั้นหลัก: ข้อความแรก (แยกทางเข้า คอมเมนต์หรือ keyword), ดูตัวอย่าง, ข้อ FAQ ที่กด, กดซื้อ
  ส่งสลิป ผลตรวจ และส่งของ มาจากแอปอยู่แล้ว
- FU1 (30 นาทีหลังกดซื้อ ถ้ายังไม่ส่งสลิป) ถามเหตุผล ข้อความที่เจ้าของอนุมัติ:
  > ติดตรงไหนไหมครับ 🙏 / ถ้าโอนแล้ว ส่งรูปสลิปมาในแชทนี้ได้เลย /
  > ถ้ายังไม่ได้โอน บอกเราหน่อยได้ไหมครับว่าติดอะไร กดเลือกด้านล่างได้เลย 👇
  ปุ่ม: 💳 ยังไม่สะดวกโอนตอนนี้ · 📱 อยากจ่ายด้วย QR / พร้อมเพย์ · 🤔 ขอคิดดูก่อน · 💰 ราคายังไม่โดน
  · ❓ มีคำถามก่อนซื้อ (เดิม) · 🏦 ดูวิธีโอนอีกครั้ง (เดิม) — 4 ปุ่มแรกตอบสั้น ๆ แล้วส่ง event เหตุผล
- ไม่เพิ่มข้อความใหม่ FU2 และ FU3 เหมือนเดิม

**หน้าสรุปบน bdash** (เมนู "ขาย E-Book" ใช้ theme ของ bdash หน้าตาตามที่ทีมทำเอง แสดงตัวอย่างให้เจ้าของเลือกก่อนสร้าง)
revision 0.7: ใช้เท่าที่ข้อมูลของเรามี ส่วนที่ต้องใช้ข้อมูลแอดอยู่ใน slice 5
- ช่วงเวลา 7, 14, 28 วันหรือเลือกเอง
- "คนหลุดตรงไหนมากที่สุด?" — กดซื้อ → ส่งสลิป → ธนาคารยืนยัน → ได้ของ (ดูตัวอย่างนับแยก)
  นับคนทักเข้าจาก flow ไม่ได้ (revision 0.7)
- "ทำไมคนกดซื้อแล้วไม่โอน?" — นับจากปุ่มเหตุผลใน FU1
- "วันนี้ขายได้กี่เล่ม?" — จากสลิปที่ธนาคารยืนยัน รายวันและตามชั่วโมง
- "โค้ดแถมถูกใช้แค่ไหน?" — ส่งโค้ดไปกี่คน และกรอกแล้วกี่คน อ่านจากระบบแลกโค้ดอย่างเดียว
  โค้ดใช้ร่วมกันทุกคน จึงบอกรายคนไม่ได้

**ก่อนเปิดให้ทุกคน**
- อีเมล "✅ บอทตรวจสลิปและส่ง E-Book + โค้ดให้ {ชื่อ} แล้ว ไม่ต้องส่งซ้ำ" จาก flow ส่งของ
  ส่งถึงเจ้าของระหว่างทดสอบ แล้วเปลี่ยนเป็นทั้งทีมตอนเปิด
- IP whitelist ของ Slip2Go และเปลี่ยน key ใหม่ · เปลี่ยน hook secret ของ staging
- จ่ายแพ็กของ Slip2Go และ ManyChat Pro (trial หมด 2026-11-16 และ 2026-11-17)

**เปิดให้ทุกคน (เจ้าของสั่ง)**
- `EBOOK_OPEN=1` ใน env ของ production ไม่ต้องแก้ flow · ถอยด้วยการลบค่านี้ออก

## Acceptance

- บน staging เจ้าของเดินครบทุกทางของ flow ทดสอบ แล้วเห็นตัวเลขตรงในหน้าสรุป
- คนที่กดซื้อแล้วไม่ส่งสลิปได้ FU1 ที่มีปุ่มเหตุผลตอน 30 นาที และเหตุผลที่กดขึ้นในหน้าสรุป
- ปิดแอปแล้วเดิน flow → ลูกค้าไม่ต้องรอเพิ่ม และข้อความเดิมมาครบ
- ตัวเลขการใช้โค้ดในหน้าสรุปตรงกับระบบแลกโค้ด
- หน้าสรุปผ่านเกณฑ์หน้าภาษาไทยแบบธุรกิจ (หัวข้อเป็นคำถาม ไม่มีศัพท์เทคนิค) และหน้าเดิมของ bdash ไม่เปลี่ยน
- หลังเปิดให้ทุกคน: ลูกค้าจริงคนแรกที่ไม่ใช่เจ้าของได้ของจากบอท และทีมได้อีเมลว่าบอทส่งแล้ว
