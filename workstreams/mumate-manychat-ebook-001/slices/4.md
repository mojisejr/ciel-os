# Slice 4 — ปล่อยจริงบน production

## Scope

- migration ของตารางงานนี้รันบน Supabase production เมื่อเจ้าของสั่ง ผ่าน `bin/prod-sql.sh` ก่อน promote
- ใส่ env ของ production ทีละค่าตาม runbook 01 (ManyChat API key, key ของบริการตรวจสลิป, ยอดจริง, บัญชีผู้รับ)
- เจ้าของกด `promote-production` ให้แอปขึ้น production ด้วย SHA เดียวกับที่ผ่าน staging
- ปล่อย 2 ขั้น:
  - ขั้นแรก: flow จริงเรียกแอปเฉพาะลูกค้าที่มี tag `beta` ส่วนคนอื่นยังเป็นทางเดิมที่แอดมินทำเอง
  - ขั้นสอง: เจ้าของสั่งเปิดให้ทุกคน
- ทางถอย: ปิด External Request ใน flow จริง หรือใช้ `rollback-production` แล้วกลับไปใช้ทางเดิมของแอดมินได้ทันที
- alert ของ control room เห็นแอปตัวที่สาม (health, log silence)

## Acceptance

- ลูกค้าจริงคนแรกที่ส่งสลิปผ่านขั้น beta ได้ของอัตโนมัติ และแอดมินยืนยันว่าเงินเข้าบัญชีจริง
- ไม่มีลูกค้าคนไหนถูกทิ้ง: สลิปที่ระบบตรวจไม่ได้ไปถึงแอดมินทุกใบ
- runbook 00 และ 01 มีขั้นของแอปนี้ และเจ้าของกดถอยจากมือถือได้
