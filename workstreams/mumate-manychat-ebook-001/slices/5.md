# Slice 5 — ข้อมูลแอดจาก Meta และหยุดแอดที่ต้นทุนเกิน

revision 0.7: เปิดไว้รอ token จากทีม เริ่มเมื่อได้ token และเจ้าของสั่ง

## Scope

**ที่ทีมต้องให้ (ขอครั้งเดียว)**
- token ของ System User ใน Meta Business เข้าถึงบัญชีโฆษณา เพจ Mumate.co และ dataset ของเพจ
  สิทธิ์ `ads_read`, `ads_management`, `page_events` (และ `business_management` ถ้าต้องใช้ผูก asset)
  `page_events` ต้องได้ Advanced Access ของแอป
- Ad account ID, Page ID, Dataset ID, App ID
- เกณฑ์ "เกิน": ต้นทุนต่อคนซื้อเกิน 45 บาท หรือเกิน 50% ของราคา, เงินขั้นต่ำก่อนตัดสิน, หยุดระดับชุดแอดหรือแคมเปญ
- ที่มาของรายได้คอร์ส VDO และค่า ManyChat ต่อเดือน

**ทำตามลำดับ**
1. อ่านข้อมูลแอดแบบอ่านอย่างเดียว ขึ้นบนหน้า "ขาย E-Book": การแสดงแอด คนเห็น คนกด คนเริ่มแชท
   ค่าแอดรายวันและตามชั่วโมง ต้นทุนต่อคนซื้อเทียบเป้าและจุดคุ้มทุน 95 บาท กำไรขาดทุน (ค่าแอด VAT 7%
   ManyChat Slip2Go) และตาราง "แอดที่วิ่งอยู่" พร้อมสถานะ ผ่าน/ไม่ผ่าน ยังไม่หยุดแอดเอง ดู 3–5 วัน
2. ส่งสถานะจ่ายแล้วกลับไปที่ Meta (Conversions API สำหรับ Messenger) เมื่อธนาคารยืนยันสลิป
   ทำให้ต้นทุนต่อคนซื้อแยกรายแอดได้
3. หยุดชุดแอดที่ต้นทุนเกินเกณฑ์เอง เปิดเมื่อเจ้าของสั่ง ทำได้แค่หยุด ไม่เปิดแอดและไม่เพิ่มงบ
   แจ้ง Discord ทุกครั้งที่หยุด

**ไม่ทำ**
- เปิดแอด สร้างแอด หรือแก้งบ
- เก็บ token ใน repo หรือข้อความ ใส่ผ่าน `bin/env-set.sh` เท่านั้น

## Acceptance

- ตัวเลขค่าแอดบนหน้าตรงกับ Ads Manager ของช่วงเดียวกัน
- สถานะ ผ่าน/ไม่ผ่าน ตรงกับเกณฑ์ที่ทีมยืนยัน
- Meta เห็น Purchase จากการซื้อจริงหนึ่งครั้ง
- การหยุดแอดเอง: ชุดแอดที่เกินเกณฑ์ถูกหยุด แจ้ง Discord และไม่มีการเปิดหรือเพิ่มงบจากระบบ
