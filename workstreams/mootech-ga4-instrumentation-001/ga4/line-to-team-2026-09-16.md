# ข้อความ LINE ถึงพี่ปอง (16 ก.ย. 2026) — ฉบับสั้น

พี่ปองครับ อัปเดตเรื่อง analytics ที่ขอไว้ (DAU / Total users / Login / Sign up)

✅ ทำอะไรไปแล้ว
1. ตั้ง GA ให้นับ "สมาชิกที่ล็อกอิน" แทน "คนเข้าเว็บ" — เมื่อก่อนคนเดียวเปิด 3 เครื่องนับเป็น 3 คน ตอนนี้นับเป็น 1 และคนที่แค่เข้าหน้า landing ไม่ปนกับคนใช้แอปแล้ว
2. เพิ่ม event "login" กับ "sign_up" ใน GA (บอกด้วยว่าเข้าผ่าน LINE / Google / Facebook)
3. หน้าหลังบ้าน /ops มีตัวเลข "สมาชิก v2 ทั้งหมด" = Total users ของจริง (นับจากบัญชี) พร้อมสมาชิกใหม่วันนี้ / 7 วัน
4. GA เก็บข้อมูลย้อนหลังได้ 14 เดือน (เดิม 2 เดือน)

👀 ดูได้ที่ไหน
• Total users → bazichart.mumate.co/ops/analytics กล่อง "สมาชิก v2 ทั้งหมด" — ดูได้เลยวันนี้ ตัวเลขสด
• DAU, Login, Sign up → GA4 → เมนูซ้าย "สำรวจ" → รายงานชื่อ "Members daily" — พร้อมประมาณ 18 ก.ย. (Google ต้องประมวลผล 1–2 วัน)
  - แท็บแรก = สมาชิกที่ใช้แอปต่อวัน (1 วัน / 7 วัน)
  - แท็บ Events = จำนวน login / sign_up ต่อวัน
• อยากรู้ตอนนี้ว่ามีสมาชิกออนไลน์กี่คน → GA4 → รายงาน → เรียลไทม์ → การ์ด "ผู้ใช้ที่ใช้งานอยู่ โดย พร็อพเพอร์ตี้ผู้ใช้" → เลือก member_state

📖 อ่านยังไง
• DAU = จำนวนสมาชิกที่เปิดแอปในวันนั้น (นับคน ไม่นับเครื่อง)
• % DAU = DAU ÷ สมาชิก v2 ทั้งหมด (จาก /ops) — ตอนนี้ต้องหารเอง เดี๋ยวผมสรุปให้ในรายงาน
• ตัวเลข "วันนี้" ใน GA ยังไม่นิ่ง ดู "เมื่อวาน" เป็นหลัก
• ตัวเลขที่เชื่อได้เริ่ม 16 ก.ย. ก่อนหน้านั้นยังปนคนเข้า landing อยู่

⚠️ ข้อเดียวที่ต้องระวัง: "Total users" ที่ GA โชว์ ไม่ใช่จำนวนสมาชิก (GA นับคนเข้าชม) — จำนวนสมาชิกจริงดูที่ /ops เท่านั้น

📅 ต่อไป: เก็บข้อมูล 7 วัน แล้วประมาณ 24–25 ก.ย. ผมส่งสรุปตัวเลข + วิธีดูให้อีกที ถ้าอยากเห็นอะไรเพิ่มบอกได้เลยครับ

(ถ้าเข้า /ops หรือ GA ไม่ได้ บอกผมนะครับ เดี๋ยวเปิดสิทธิ์ให้)
