# 3. Prove one monsoon scene with Blender models anchored on map tiles

## Result and acceptance

- One inspectable silent scene, about twelve seconds, on the existing Mac.
  Geographic map tiles remain visible while the camera moves and original
  Blender models stay anchored in the same rendered world.
- Export original orchard/cloud components to GLB; prepare portable materials.
  Use Three.js inside MapLibre's custom 3D layer, not an unrelated garden
  background substituted for the map. Clearly enlarged illustrative models.
- Original frame-driven seasonal southwest flow, not current forecast data.
  No invented weather measurements, dates or field-level irrigation advice.
- State attention/camera phases before building; inspect representative stills
  before full capture, and encoded opening/middle/ending after it.
- Scope a small OpenFreeMap area. Respect attribution, bounded offline request
  and byte limits; cache only needed public assets with an identifying agent.
  Keep third-party package pinned/verified in ignored local tool storage.
- Modest portrait output and bounded capture time/resources. Record time,
  sampled owned-process RSS, system snapshots and their measurement limits.
  No claim that this proves 1080p full-film capacity or complete Windy accuracy.
- Verify file stream/duration/decode, geographic/model alignment evidence and
  original-style/delivery preservation. Keep bulky media and cache ignored.
- No new paid API call, account, cloud renderer, upload, posting, global
  setting, package/CI rewrite or unrelated change. Present a local preview;
  owner feedback determines the next style/story step.
