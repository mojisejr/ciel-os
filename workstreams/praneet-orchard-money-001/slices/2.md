# 2. จ่าย

1. **praneet-web:** หน้าจ่ายแบบหนึ่งบิลหลายรายการ ตาราง บิลจ่าย รายการจ่าย และคำกับหมวด ตาม plan 0.2
   รายการของรอบนี้ แก้หรือซ่อนได้แบบเดียวกับงาน ของใช้หลายปีพร้อมปีที่ซื้อ (ใส่ย้อนหลังได้)
   เลือกของจากชั้นยาแล้วตั้งเป็น "มี" ลิงก์ "เงินสวน" จากหน้างานสวน
   และ migration ที่รันบน production ก่อน merge ตามคำของเจ้าของ
2. **praneet-office:** `money spend` บันทึกและอ่านรายการจ่าย ลองก่อนเขียนเหมือน `orchard add` ตาม runbook 08

## Acceptance

- จ่ายหนึ่งบิลหลายรายการบนมือถือได้ในไม่กี่แตะ ยอดรวมบิลเท่ากับผลรวมรายการ หมวดถูกจัดจากคำโดยเจ้าของไม่ต้องเลือก
- ของใช้หลายปีตกรอบละ ราคา ÷ ปีที่ใช้ นับจากปีที่ซื้อ ของที่ซื้อก่อนใช้ระบบนับเฉพาะปีที่เหลือ (มีเทสต์)
- หน้าไม่แน่นขึ้นจากช่องที่ไม่บังคับ ตามตัวอย่างแบบ B ที่เจ้าของเลือก
