## เป้าหมายและข้อตกลงกับเจ้าของ (syncup 2 รอบ, 2026-11-02, เดาตรง 16/16)

บันทึกเงินที่จ่ายและผลผลิตที่ขายของสวนให้ง่ายและคล่อง แล้วตอบได้ว่าแต่ละรอบผลผลิตลงไปเท่าไหร่ กำไรเท่าไหร่
ทำดีขึ้นกว่ารอบก่อนไหม ต่างจากเดิมตรงไหน โดยเงินเชื่อมกับประวัติงานของ `praneet-orchard-001` ในระบบเดียวกัน
ชาวสวนไม่ต้องรู้ศัพท์บัญชี ต้นทุนคงที่ ผันแปร และค่าเสื่อม แฝงอยู่ในรายงาน

- **จ่าย:** วันที่ ซื้ออะไร (แตะคำที่ใช้บ่อย หรือเลือกจากชั้นยา) กี่บาท แปลงไม่บังคับ ระบบจัดหมวดเองจากคำ
  "ใช้ได้หลายปี" ติ๊กเองแล้วใส่กี่ปี ไม่มีเกณฑ์ราคา ซื้อยาแยกจากจัดการยา แต่ตั้งชั้นยาเป็น "มี" ให้
- **ขาย:** ทุเรียน มังคุด หรือชนิดที่เพิ่มเอง เป็นกิโลแยกไซซ์ (ราคาต่อกิโล × กิโล) หรือขายเหมาเป็นยอดเดียว
  ไซซ์ตั้งชื่อเอง เพิ่มลดได้ ระบบจำชุดไซซ์ของแต่ละชนิด ผู้ซื้อและจำนวนลูกไม่บังคับ
- **ค่าแรง:** มาจากงานที่บันทึกแล้ว นับตามวันทำงาน ไม่ใช่วันจ่าย ค่าแรงค้างจ่ายแสดงแยก เงินเบิกไม่ใช่ต้นทุน
- **รอบผลผลิต:** ปุ่มเดียวทั้งสวน "เก็บผลเสร็จแล้ว ปิดรอบนี้" กดหลังเก็บชนิดสุดท้ายเสร็จ รอบใหม่เริ่มวันถัดไป
  กดผิดเอาคืนได้ คนที่เริ่มกลางทาง รอบแรกเริ่มวันแรกที่บันทึก ติดป้ายว่าไม่เต็มรอบ และบอกตอนเทียบ
- **จำนวนต้น:** ต่อแปลงต่อชนิด ไม่บังคับ แก้ได้ทุกรอบ
- **สรุป:** ลงไปเท่าไหร่ ขายได้เท่าไหร่ เหลือเท่าไหร่ กำไรต่อต้น เฉลี่ยต่อกิโล ต่อลูก ราคาเฉลี่ยแต่ละไซซ์
  เทียบรอบก่อนว่าหมวดไหนมากขึ้น กดดูงานเบื้องหลังได้ ตัวไหนคิดไม่ได้ บอกว่าขาดข้อมูลอะไร
- **ถ้าจะยื่นภาษี (ไม่บังคับ):** หักเหมา 60% เทียบหักตามจริง ใช้วิธีคิดเดียวกับ DAC2 (`crates/calc/src/tax.rs`)
  บอกว่าเป็นตัวเลขประมาณก่อนลดหย่อนส่วนตัว DAC2 เลิกใช้แล้ว ยืมวิธีคิดเท่านั้น ไม่ส่งข้อมูลถึงกัน
- **ปีก่อน ๆ:** ใส่ยอดรวมได้ ไม่บังคับ ไม่ใส่ รอบแรกคือรอบที่เริ่มบันทึก
- **praneet-office:** agent บันทึกจ่าย ขาย ปิดรอบ และอ่านสรุปจากแชทได้เมื่อเจ้าของสั่ง เช่น อ่านรูปบิลแล้วบันทึก
  โดยไม่เก็บรูป
- **ปฏิทิน:** ไม่ลง เพราะปฏิทินไม่มีเงิน
- **หน้าตา:** ออกแบบทั้ง flow ก่อน แล้วเลือกจากตัวอย่างบนหน้าจริงก่อนสร้างทุกหน้า

## ข้อตกลงจาก slice 1 (revision 0.2, 2026-11-02)

เจ้าของเลือกตามที่ agent เอนทั้งหมด จากตัวอย่างบนหน้าจริงในเครื่อง และย้ำว่า "ขอใช้ง่ายไม่รก ตอนนี้ใช้คนเดียว"

- **ง่ายไม่รก:** ตอนนี้เจ้าของใช้คนเดียว จึงไม่สร้างอะไรเผื่อหลายคน หลายสวน หรือสิทธิ์ผู้ใช้
  ช่องที่ไม่บังคับไม่ทำให้หน้าแน่น เจ้าของเล่าว่าใช้ไปสักพักอาจทำให้ทุกคนใช้ได้แล้ววางแผนหาเงิน
  เรื่องนั้นยังไม่ใช่งานของแผนนี้
- **ทางเข้า:** หน้างานสวนมีลิงก์ "เงินสวน" ไปหน้าสรุปของรอบนี้ ซึ่งมีปุ่ม + จ่าย และ + ขาย อยู่บนสุด
- **หน้าจ่าย แบบ B:** หนึ่งบิลหลายรายการ บิลมีวันที่ ร้านและหมายเหตุไม่บังคับ แต่ละรายการมีคำ บาท แปลงไม่บังคับ
  ใช้กี่ปี และยาจากชั้นยา ยอดรวมบิลแสดงตลอดเพื่อเทียบกับบิลจริง
- **หน้าขาย แบบ A:** ไซซ์เป็นแถว แต่ละแถวใส่บาทต่อกิโลกับกี่กิโล ไซซ์ที่ไม่ได้ขายปล่อยว่าง หรือเลือกขายเหมาเป็นยอดเดียว
- **หน้าสรุป แบบ A:** ตอบเป็นคำถาม ลงไป ขายได้ เหลือ ต่อหน่วย ราคาแต่ละไซซ์ เทียบรอบก่อนแบบแตะดูเบื้องหลังได้
  ภาษี จำนวนต้น รอบก่อน ๆ และปิดรอบ
- **โครงข้อมูล:** ตารางใหม่ ไม่แตะตารางงานและค่าแรงเดิม ทุกอย่างแก้หรือซ่อนได้และเก็บประวัติก่อนหลังเหมือนงาน

  | ตาราง | เก็บ |
  |---|---|
  | บิลจ่าย | วันที่ ร้าน หมายเหตุ |
  | รายการจ่าย | คำ หมวด (มาจากคำ) บาท แปลง ใช้กี่ปี (ว่าง = หมดในรอบ) ปีที่ซื้อ ยาจากชั้นยา |
  | คำกับหมวด | คำที่ใช้บ่อยและหมวดของคำ แก้หมวดของคำครั้งเดียวใช้ทุกครั้ง |
  | ชนิดผลผลิตและไซซ์ | ชนิด ชื่อไซซ์ ลำดับ ซ่อนได้ |
  | การขาย | วันที่ ชนิด แบบ (กิโล หรือเหมา) ยอดเหมา ผู้ซื้อ กี่ลูก |
  | แถวของการขาย | ชื่อไซซ์ (คัดลอกไว้ เปลี่ยนชื่อทีหลังการขายเก่าไม่เปลี่ยน) บาทต่อกิโล กิโล |
  | รอบ | วันที่เก็บเสร็จ (ไม่ซ้ำ) ยอดรวมที่ใส่เองของปีก่อนใช้ระบบ |
  | จำนวนต้น | รอบ แปลง ชนิด กี่ต้น ยกจากรอบก่อนให้เอง |

- **งานเดียวหลายแปลงที่มี P-4:** ค่าแรงหารเท่า ๆ กันตามจำนวนแปลง ส่วนของ P-4 ไม่นับ
- **ของหลายปีที่ซื้อก่อนใช้ระบบ:** ใส่ย้อนหลังได้พร้อมปีที่ซื้อ ระบบนับเฉพาะปีที่เหลือ
- **คำตั้งต้น:** ใช้ชุดนี้เริ่ม แล้วเจ้าของแก้ในหน้าจริง
  - หมวด: ปุ๋ย · ยาและฮอร์โมน · น้ำมันและไฟ · ซ่อมและอะไหล่ · อุปกรณ์ · จ้างเหมาและบริการ · ขนส่ง · อื่น ๆ
    และค่าแรงที่มาจากงานเอง
  - คำที่ใช้บ่อย: ปุ๋ยเคมี ปุ๋ยคอก ปุ๋ยทางใบ ยาฆ่าแมลง ยากันรา ฮอร์โมน น้ำมันโซล่า ค่าไฟปั๊ม สายยาง
    หัวสปริงเกอร์ ซ่อมเครื่องพ่น ซ่อมเครื่องตัดหญ้า จ้างโดรนพ่นยา เชือกโยงกิ่ง และยาทุกตัวบนชั้นยา
  - ไซซ์ทุเรียน: AB · C · D (ตกไซซ์) ไซซ์มังคุด: มันใหญ่ · มันเล็ก · ลาย · ตกไซซ์
- **คำสั่ง office:** `money spend` `money sale` `money close` และอ่านสรุป ทุกคำสั่งลองก่อนเขียน บอกปลายทาง
  และปฏิเสธตัวเลือกที่ไม่รู้จัก ตาม runbook 08 ของ praneet-office
